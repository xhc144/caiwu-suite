# caiwu-suite 单机财务软件套件

自主开发的单机版财务软件，参考市面上同类产品的功能和操作习惯，重新设计实现（不使用原软件的代码、图标和图片）。

## 计划中的产品线

| 产品 | 参考对象 | 适用会计制度 |
|---|---|---|
| 轻松会计 | 轻松会计单机版 | 企业会计准则 / 小企业会计准则 |
| 民非企会计 | 民非企单机版 | 民间非营利组织会计制度 |
| 成本会计 | 成本会计单机版 | 企业成本核算 |

## 技术选型（暂定）

- C# .NET 8 WinForms（Windows 原生控件，贴近传统财务软件的操作手感）
- SQLite（单文件账套，便于备份）
