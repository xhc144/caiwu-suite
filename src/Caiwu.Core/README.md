# 账务领域核心

`LedgerService(ILedgerStore)` 实现冻结的 `ILedgerService` 全部方法，不持有缓存、不释放调用方的 store。每次命令先读最新快照，只调用一次带 expected revision 的 `Write`；业务变动、revision 增量和审计记录一起提交。失败不重试，不吞掉系统或并发异常。原子持久化与跨进程 revision 校验最终由 store 契约负责，本项目不实现 SQLite。

金额只用 decimal：禁止负数、有效精度超过两位、单行借贷同填和超过 `Int64` 分的金额；不静默舍入。凭证至少两行且借贷相等，只能使用启用的末级科目。期初余额借贷相等，首笔记账或首次结账后冻结。

凭证流程为草稿→审核→不可逆记账。审核前可修改、删除草稿；未记账的审核可以取消，再次记账前必须重新审核。记账后所有编辑、删除、取消审核和重复记账均拒绝。制单人与审核人的名字按 trim、Unicode FormKC、大小写无关比较，修改草稿的人成为当前制单人。接口只提供名字，用户认证及权限校验仍由调用方负责。

期间为单会计年度、启用月到12月；所有凭证写操作均检查原日期和目标日期的期间锁。结账只能逐月前进，该月任何未记账凭证都会阻断结账。关闭空月可行，未来月份的草稿不阻断当前月。没有反记账、反结账、跨年结转接口。

编号在年度、月份、凭证字内唯一。新建自动取现有最大号加一；同组草稿编辑且 Number=null 时保留原编号，换组后自动分配。编号用尽或冲突拒绝提交。删除草稿可能留下空号，未实现连续编号整理或更正凭证关联流程，不能据此声称符合全部软件规范。

科目编码为4—32位ASCII数字，子级必须以前缀包含父级编码，但父子关系仅由 ParentCode 确定；相同前缀不自动视为父子。父级必须存在，不能循环、不能让启用子级隶属停用父级、不能给非末级设置期初。已有凭证引用的末级不能增加子级。已有凭证或非零期初的子树不能修改其方向或上级关系；名称可改，启用状态控制新的业务使用。有子级、非零期初或任意状态凭证引用的科目不能删除。

`SetOpeningBalances` 是**整体替换**：未列出的启用科目余额归零。停用末级科目可以原样提交已有期初（包括零）；不得给它新增、更改或清除期初，修改前必须先启用。停用科目已有非零期初时，遗漏该行也会拒绝整次保存，避免过滤停用行后静默清零。重复科目、无效/非末级科目及不平衡请求仍全部原子拒绝。这个例外只用于期初展示/保存，凭证保存、审核和记账仍禁止使用停用科目。`SaveAccount` 的期初变动同样受整体借贷平衡与期初锁限制；有凭证引用时请通过整体期初设置入口处理（仅首笔记账前）。

报表只取已记账分录，日期边界包含两端。期初加上查询开始日之前的发生净额；明细账按日期、凭证字、编号、ID、分录原顺序排列，借正贷负，首行始终为期初余额。每条发生额保留凭证ID/日期/字/号，调用方可从 `GetSnapshot` 联查原凭证。父级余额表按所有末级各金额栏求和，保留不同子级的相反余额；界面总计必须只加 `IsLeaf`。父级明细账包含其真实子树分录，运行余额取带符号净额。

快照、分录和模板目录均返回独立的只读列表，调用方修改输入数组不会影响已提交状态。

## 模板与未验范围

三个独立ID/版本的模板均为 `IsVerifiedForProduction=false`。小企业与企业采用各自的资本、收入、费用、本年利润编码。民非采用2026正式附录的存货1201、两类净资产3101/3102、管理费用5301，并给出捐赠收入/业务活动成本/管理费用的限定性与非限定性明细示例；明细编码为本项目演示选择。民非没有企业实收资本、本年利润或主营业务收入，不强行套用企业算例。

尚未实现或验收：完整制度与科目覆盖、限制条件证据管理、收入确认判断、自动损益/两类净资产结转、历史迁移、更正凭证流程、税务报表、电子凭证归档、Windows界面、真实SQLite跨进程事务及灾备。月结这里只锁期间，不能解释为已完成损益结转或法定年结。
