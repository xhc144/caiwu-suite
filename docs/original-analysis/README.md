# 原版财务软件静态分析（轻松会计 / 民非企 / 成本会计）

这份说明是重做 caiwu-suite 的依据。内容来自对三个原版安装包的**静态反编译**，没有运行原程序，也不依赖手册截图。菜单、窗口、控件、按钮动作、提示语和表结构都直接取自程序里编译好的对象。

> 用法：做某个功能前，先在下面的「功能地图」找到对应的子系统，再打开它的 `menus.md` 查菜单项和快捷键，然后到 `windows/*.md` 查该窗口的控件布局、数据列、按钮动作和校验提示，最后在 `data/tables.md` 查要读写的表。需要程序化处理时读 `json/` 下的机器可读文件。

## 一、三套产品的构成

三套软件同出一个 PowerBuilder 9 代码基线（润衡财务软件 8/9 版），账务核心相同，区别在于打包了哪些子系统。

| 子系统 | 轻松会计 | 民非企 | 成本会计 | 程序/库 |
|---|:-:|:-:|:-:|---|
| 账务（凭证、账簿、报表、财务分析、合同） | ✓ | ✓ | ✓ | 主程序 `run_zw8.exe` / `rhzw8_mfq.exe` / `rhzw8_cb.exe` + `rhzw8_1~9.pbd`、`rhzw_root.pbd` |
| 工资（人事、工资表、工资条、工资凭证） |  | ✓ | ✓ | 主程序内，`rhzw8_gz1.pbd` |
| 固定资产（卡片、折旧、资产报表） |  | ✓ | ✓ | 主程序内，`rhzw8_zc1.pbd` |
| 成本 / 仓库进销存（出入库单、库存、盘点、成本核算） |  |  | ✓ | 主程序内，`rhzw8_cb1/cb2.pbd` |
| 出纳（单据录入、日记账、对账勾账、凭证生成） | ✓ | ✓ | ✓ | 独立程序 `rhzw9_cn0.exe` + `rhzw9_cn0~2.pbd`、`rhzw9_root.pbd`（**三套完全相同**） |
| 发票（进项/销项发票、增值税比对、发票凭证） | ✓ |  | ✓ | 独立程序 `rhzw9_fp0.exe` + `rhzw9_g/g1.pbd`（轻松与成本完全相同） |

补充说明：

- “民非企”不是单独的一套民非账务程序。它的民非能力来自新建账套时选择的**会计制度模板**（`a54`「民间非营利组织会计准则(2026)」等，见 [data/tables.md](data/tables.md#账套模板新建账套时选择的会计制度)）以及对应的报表格式。账务窗口与轻松会计同名同功能。三套的 `rhzw8_*.pbd` 字节不同，细节可能有出入，做到具体窗口时以各产品自己的 `windows/` 文档为准。
- 主程序是 MDI 结构，主框架窗口为 `w_frame`。在工作台点击“工资”“固定资产”“仓库”图标，会通过 `w_login_qhmk` 切换到对应子系统，并打开该子系统的工作台 sheet（`w_main1_gz` / `w_main1_zc` / `w_main1_cb`）。这些工作台各自带有子系统主菜单（`m_frame_gz` / `m_frame_zc` / `m_frame_cb`），MDI 下打开工作台后菜单栏就切换成该子系统的菜单。
- 打开功能窗口（sheet）时，菜单栏换成该窗口自带的菜单。这些菜单继承主菜单，再加一个「O.操作」菜单，带工具栏按钮，例如凭证序时簿的 审核 F4、反冲、批量审核、凭证转入/转出。

## 三、核心业务流程与关键规则（摘自程序提示语）

**账务月度流程**：凭证输入 → 凭证审核 → 凭证过帐 → 月度结转（损益结转凭证）→ 结帐。对应的逆操作分别是反审核、反过账、反结账（都在“系统管理”菜单）。

- 审核：制单人与审核人相同的凭证不能审核（批量审核时跳过并提示“建议更换用户后再进行审核”）；没设置现金流量的凭证会提示是否继续。
- 过账：“年初数不平，不能进行过帐处理”；“请先录入期初数”；“已经结帐，不能过帐”；试用版超过 500 张凭证不能过账；可选择重新生成月度结转的自动凭证。
- 月度结转：“本月还有 N 张凭证未过帐，不能自动结转”；已结账月份要先反结账。
- 结帐：“本月还有未过账凭证，不能结账”；凭证编号不连续时提示，并可让系统自动重排编号（会影响已打印的凭证和账册）。
- 反结账：一直反到开账日期为止；从 1 月以后反结账会删除当年年初数。反过账：已结账的月份不能反过账。
- 期初：本年有过账后，不能再增加期初数；只有数量科目、复币科目才能录入对应的数量或外币期初。

**出纳流程**：出纳初始化（会清空出纳数据）→ 期初数录入 → 单据录入（按账户/账册）→ 凭证生成（每条单据生成一张，或本月汇总生成一张；可选应收/应付/利息等对方科目自动匹配方式）→ 和账务对账（勾账：按日期把金额一致的单据与已过账凭证勾销，金额不一致不能勾账）→ 出纳结账 / 反结账。已生成凭证的单据不能直接修改或删除；凭证已审核则不能删除。

每个窗口的全部提示语及触发条件见各子系统的 `rules.md`，共约 6,000 条。

## 五、方法与可信度

1. **解包**：用仓库分支 `codex/minfeiqi-static-local-20261025` 中的 `tools/pb-static-toolkit` 从安装包的 zlib 载荷中恢复文件，并用清单 SHA256 校验。453 条记录恢复了 447 条，跳过的 6 条都是重复的 `asa8\dbmsql9.dll`。
2. **反编译**：使用开源 PbdViewer（[Hucxy/PbdViewer](https://github.com/Hucxy/PbdViewer)，MIT，提交 b46fd3e），改造成命令行导出器。修正了以下问题：GBK 编码、系统资源加载、Ordinal 比较、ANSI SQL 参数的字节偏移、提前 return 被误删、SQL 游标声明被隐藏。8 个程序共 7,071 个对象，0 个导出失败。PB 按库列表顺序解析同名对象（先到先得），本分析也按这个顺序取对象。
3. **DataWindow 与表结构**：DataWindow 由 pb-static-toolkit 的 `pb_deep_dw.py` 解析，得到列、查询和列标题候选。表结构来自 180 个账套模板归档中的 `data_stru.txt` DDL，0 条解析失败。
4. **生成**：仓库根目录 `tools/original-analysis/`（`gen.py`、`render.py`、`tables.py`）只读取导出的 JSON，再生成本目录内容。导出器源码在 `tools/pbdviewer-export/`。重新生成的步骤见 [tools/original-analysis/README.md](../../tools/original-analysis/README.md)。

已知限制，使用时需要注意：

- 提示语只保留了字面文字。拼接进去的变量（张数、科目号等）被省略，所以会看到“本次审核共成功审核张凭证”这样的句子。“条件”取的是提示语之前最近的一个 `if`，嵌套分支需要回到源码复核。
- 菜单项的“默认隐藏/禁用”是设计时的属性。运行时脚本可能按版本、OEM、权限或已购模块重新显示或隐藏它们。
- 窗口“打开入口”只统计静态调用：`open(w_x)`、字符串 `"w_x"`、经全局函数打开的情况。动态拼名打开的窗口会漏掉。
- DataWindow 的字体、像素坐标、编辑风格、数据类型等可视属性还没有完整解码。列标题是“候选”（按版面位置匹配）。窗口控件的坐标是 PBU，可以直接用来还原布局比例。
- 本目录不含原软件的源码、图片或可执行文件，只有结构化描述和必要的提示语引用。原始反编译输出保存在本机工作目录，没有提交到 Git。
