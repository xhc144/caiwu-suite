## 民非专属

原版民非能力 = 民非 2026 会计制度模板（科目体系）+ 对应报表格式，账务流程与企业账套相同。新版的“民非报表分类与预览”只能预览，主账务只读，且不能新建民非账套。应改为：民非账套与普通账套走同一套账务流程，差别只在科目模板和报表模板。

## 建议的重做顺序

1. **账务主线补齐**：辅助核算（项目/客供/部门/人员）、外币、数量；凭证序时簿的全部操作；反过账、反结账、月度结转、断号检查；总账、日记账、多栏账、辅助账；余额表全系列。
2. **会计制度模板**：按 data/tables.md 中的 44 个模板建立科目体系；先做企业、小企业、民非 2026。
3. **报表与分析**：单元格报表与取数函数、法定报表模板、财务分析、账龄分析。
4. **出纳**（三套都需要）。
5. **工资、固定资产**（民非企、成本）。
6. **成本/仓库进销存、发票**（成本、轻松）。
7. 原版账套导入（读取 SQL Anywhere 数据，可选）。
