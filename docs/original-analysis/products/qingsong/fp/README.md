- **O日常业务**：销项发票录入、进项发票录入、发票处理、增值税比对、结账
- **S系统管理**：系统初始化、销项发票参数设置、进项发票参数设置、反结账
- **W.窗口**：级联排列 Shift+F5、水平排列、垂直排列 Shift+F4、窗口铺满、排列图标
- **H.帮助**：版权信息、计算器 Ctrl+F12
