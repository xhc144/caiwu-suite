# 要改掉的难用点（全局规则，每个相关任务都要落实；我可能会补充）

1. **合成一个程序**：原版的出纳和发票是独立程序（rhzw9_cn0.exe、rhzw9_fp0.exe），要靠"从账务系统转入""和账务对账"来回搬数据。新版全部放进同一个程序、同一个账套库，单据和凭证能双向联查。
2. **不切换子系统**：原版进工资、资产、仓库要经过 w_login_qhmk 切换，整条菜单栏都会被替换。新版用统一的左侧导航和多标签页，可以同时开着凭证和工资表。
3. **少弹窗**：原版是 MDI 加大量模态对话框，很多功能要先弹条件框（例如期初录入要先弹"选择年份" w_xt_ye_nf）。新版把条件放在页面顶部的筛选栏，编辑用页内表格或侧边抽屉。
4. **提示要能操作**：原版"本月还有N张凭证未过帐，不能自动结转"这类拦截，新版要列出具体是哪些凭证，并给出"去处理"按钮。
5. **结账检查放一页**：未过账、断号、试算不平、损益未结转等检查项全部列在一页，逐项处理；也可以一键完成"过账 → 结转 → 结账"。
6. **撤销就地做**：原版的反审核、反过账、反结账藏在"系统管理"菜单里。新版在凭证列表和期间状态页直接操作，受权限控制，写操作日志，并说清后果。
7. **录入更快**：科目、辅助项、摘要、往来单位都支持按编码、名称、拼音首字母模糊搜索；凭证可以全键盘录入，"=" 键自动找平；能从 Excel 粘贴分录；草稿自动保存。
8. **科目级次可配置**：不再因为级次是 4-3-3 还是 4-2-2 就拆成两个模板。
9. **去掉这些**：试用版"超过 500 张凭证不能过账"的限制、加密狗和注册、云报表和移动端、官方网站和公众号入口。
10. **备份**：自动备份默认开启；备份能换电脑恢复；恢复前能看到备份里的账套和期间；恢复前自动备份当前数据。
11. **Excel 导入导出到处可用**：科目、辅助档案、期初、凭证、工资、资产卡片、出入库单、发票都支持。
12. **个税**：按现行的累计预扣法计算（含专项附加扣除），替代原版的"个税起征点"设置。
13. **危险操作要保护**：系统初始化、跨年反结账、删除账套之前先自动备份，再要求用户输入文字确认。
14. **表格**：列宽可调并记住；高分屏和缩放下显示正常。
15. 【我的补充：】
