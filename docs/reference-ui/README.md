## 补证流程

原UI观察任务统一补齐主菜单→子页→弹窗→右键菜单→错误/禁用状态和返回路径。新证据回传后由主集成更新pages.json的source、runtime_state、字段/快捷键和版本，不覆盖旧证据年代。尚未见到的页面保持`pending`，可以先实现已知的业务闭环，但不得拿空页冒充原版相似度已验。

`implementation`是自研路由，不是原软件已见证据。原说明书中的反记账路径仅作为历史操作记录；新代码须服从已核现行规则的不可逆记账要求。
