# 示范模块（example）

只在开发模式显示。用来演示一个业务模块的完整写法，新模块复制这个目录改名即可。

功能：示范记账单。录入日期、摘要、借贷科目、金额（借方科目启用了部门核算时还要选部门），一键生成凭证，也可以删除生成的凭证。

演示到的约定：

| 内容 | 位置 |
|---|---|
| 清单：权限点、菜单（含全局快捷键）、来源单据 | `manifest.ts` |
| 前后端共用的输入格式 | `shared.ts` |
| 自己的表（`example_` 前缀）和 Kysely 类型 | `server/migrations.ts` |
| 业务规则（已生成凭证不能改删）、事务里生成凭证 | `server/service.ts` |
| 每个 mutation 都声明权限 | `server/router.ts` |
| 筛选条件放地址栏、数据表格、侧边抽屉表单、页面快捷键 | `web/MemoPage.tsx` |
| 服务端测试：接口、规则、权限 | `test/memo.test.ts` |
| E2E：全键盘录入、拼音搜科目、生成凭证 | `e2e/memo.spec.ts` |
