# 过账与结账

入口 `/m/period-close`，菜单「期末处理」。检查期间、操作范围和来源联查保存在网址中。

- `w_zw_jz` / `_pl`：检查真实期初、上年度年结和期间后，批量过账已审核凭证；分页读取全部凭证，列出未过账原因，中途失败整批回滚。
- `w_zw_fgz`：按年度、月份范围反过账；已结月份、后期结转和年结依赖会阻止，保留审核信息并记录操作。
- `w_xt_jzwh`：结转类型可新增、编辑、删除、启停及排序，检查唯一末级转入、转出范围重叠、辅助项、现金流方向和来源占用。
- 自定义转出支持余额、借方余额、贷方余额、本期借方发生额、本期贷方发生额、本期净发生额六类，按各辅助项计算比例并四舍五入。发生额只含本期已过账凭证及本次前序成功结转；红字冲减原侧，贷方基数采用贷方方向。
- 借贷余额按每个末级科目、项目、客供、部门、个人和币种分别筛选；本币为零时依次用外币、数量确定方向。现金流量项目不拆分余额桶。
- `w_zw_ydjz` / `_1` / `_1_bak1`：损益按科目类别识别，显式指定利润或结余转入，生成前展示执行顺序和逐步更新的分录。整批办理保留原子回滚、并发幂等和来源保护。
- `w_zw_ydjz_1_bak`：逐项结转保存已确认的顺序及进度，关闭页面后可恢复；每项预览后确认，失败可重试、明确跳过继续或停止，保留前序成功项。后项按真实成功结果重算，前序凭证删除、作废或基数变化会阻止继续。
- 转出保留辅助、外币和数量，支持零本币但有外币或数量的真实分录；转入外币按显式汇率、数量按显式本币单价换算，不沿用转出单位。手工编号账套可在整批或逐项预览中填写凭证号，冲突不写入。
- `w_xt_fbwh` / `u_hlgl`：按期间保存期末汇率、需折算的货币性末级外币科目、各币种汇兑损益科目及辅助项。预览逐桶列出外币余额、账面本币、折算本币和差额；仅调整本币，外币和数量不变，不作为实际现金收付。
- 汇兑凭证支持手工或自动编号、过期预览检查、并发幂等和来源联查；撤销先预览编号影响，确认后整体删除，可修改汇率重新生成。先办理汇兑并由其他操作员审核过账，再办理损益结转。
- `w_zw_fz` / `f_pzbh_zl`：检查期初、试算、未过账、断号、损益和期间顺序；编号整理先预览并两次确认，草稿及损益未转分别明确确认。连续结账逐月预检并原子执行，不自动年结。
- `w_zw_qxfz`：同年向前反结账保留期初；跨年须先清理后年度业务，预览并在线备份，再文字确认撤销最近派生快照。未结束的逐项结转会阻止，已结束记录在影响预览列明，完整保留在备份中；备份后变化或执行失败不改账。
- 年结按末级科目、四类辅助和币种承接本币、外币及数量，累计归零；原时钟版、试用版和凭证数量限制不保留。

取数口径依据原版静态资料中的 `w_xt_jzwh`、`jzlx.bz0`、`w_xt_fbwh` 和 `u_hlgl`。静态资料没有给出旧版转出类型枚举，六类采用上述明确口径，不把未知旧值映射成某一类型；汇兑范围由会计人员明确选择货币性项目，不自动重估所有外币科目。

未完成及限制：

- 共享现金流量汇总尚未单列汇率影响：银行、现金外币科目的汇兑调整目前会被共享查询列为未分配，需共享层识别汇兑来源并单列，不能在本模块复制账簿取数。
- 每期汇兑目前生成一张凭证，受正式凭证 999 行上限约束，最多容纳 499 个非零差额桶；尚未拆分多张，不能缩小范围后追加剩余部分。
- 仅一行零本币辅助调整仍受正式凭证至少两行的约束，预览明确阻止；不会补造无业务内容的对应行。
- 过账时自动调整已有结转凭证尚未接入；当前须合法撤销、重新预览和生成，不能绕过审核与来源锁。
- 一次跨年范围反结账仍分阶段办理。加载其他业务来源模块时，逆年结尚未接入统一期间依赖检查；保留阻止，不猜测删除其未生成凭证业务。
