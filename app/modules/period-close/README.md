# 过账与结账（M07 / W2-11）

入口 `/m/period-close`，菜单「期末处理」。原菜单的过账、月度结转、结账、反过账、反结账及结转类型维护集中在此页，期间及操作范围保存在 URL。

- 已实现 `w_zw_jz` / `_pl`（凭证管理 → 凭证过帐）：实际期初已保存、年初和启用前累计分别平衡、上年已年结、范围存在且开放后，仅过已审核有效凭证。全量分页，无 500 张限制；列出跳过原因及无待过账提示；中途失败回滚。
- 已实现 `w_zw_fgz`（系统管理 → 反过账）：年度/月范围含全年，经核心原子反过账，保留审核信息并记日志；缺范围、已结月份及后期结转依赖会阻止。
- 已实现 `w_xt_jzwh`（基础档案 → 结转类型维护）：代码、说明、凭证类型、摘要、顺序、唯一启用末级转入、转出范围及比例；新增、编辑、删除、启停、预览。缺凭证类型、转入/转出重复、父子重叠、非末级转入和无转出均阻止；使用中的定义受保护。现金流量科目分别设置流入/流出项目，生成前按实际现金增减核对。
- 已实现 `w_zw_ydjz`（账务处理 → 月度结转）：上年年结、开放期间及本月正式凭证全部过账前置；列出未过账凭证，草稿另警示。
- 已实现 `w_zw_ydjz_1` / `_1_bak1`：选择类型、修改设置、确认执行顺序和逐步更新基数后的明细；类别识别损益并显式设置利润/结余转入。保留转出辅助、外币、数量，整数分与十进制比例；来源联查、并发幂等、整批回滚、合法删除重建；后期结转和同月前序依赖保护。本次补显式“全选启用结转类型”，停用项不选。
- 已实现 `w_zw_ydjz_1_bak` / `_ts`、`f_ydjz_1_bak/_bak1/_new_bak`：同一真实生成接口，校验唯一末级转入及非空转出；零转出不生成空凭证；错误不报成功，完成提示后可修改设置。
- 本次实现 `w_xt_jzwh` / `w_zw_ydjz_1_bak` 的既有缺项：转入外币按显式“本币元/外币”汇率换算到外币分；转入数量按显式本币单价“元/单位”换算到六位小数，均四舍五入。配置绑定币种和单位，预览显示汇率、单价及实际分录；缺配置、非正数、档案不匹配、越界、过期预览均阻止，不沿用转出数量/外币。生成仍为待审核来源凭证，可合法撤销重建并进入年结/受管逆年结。
- 已实现 `w_zw_fz`（账务处理 → 结帐）/ `f_pzbh_zl`：检查期初、试算、未过账、断号、损益和顺序。仅结最早开放月；作废占号、草稿无号。编号先预览新旧号，再两次确认影响打印且不可直接恢复，整理后重检。草稿及损益未转须分别明确确认并记日志。一键流程停在结转预览及真实异人审核检查点。
- 本次实现 `w_zw_fz`“连续结账”：操作范围内同年、从最早开放月开始，先逐月预览；正式账、损益、断号、期初或草稿有问题则定位并阻止整批。确认时重检预览版本，同一事务顺序结账，中途失败连同日志回滚；保留原账和期初。需要特殊确认的草稿/损益回到单月办理，不自动年结。
- 已实现 `w_zw_qxfz`（系统管理 → 反结账）：最近已结月向前的范围含当年全部已结月份，最多至启用月；同年保留手工期初。跨年按「后年度撤销业务及结账 → 逆年结预览 → SQLite 在线备份 → 输入文字再次确认 → 前年度逐月反结」办理。只撤销可核实且未使用的最近派生快照；备份失败、取消、快照变化、后年度业务/缺失数据、事务失败均不改账。备份及元数据在运行时 `period-close/backups/<账套ID>/`，不接受用户绝对路径。
- 已实现年结：全年已结、试算及损益完成、目标年度无手工期初或业务后，在同一事务建立期间并按末级科目、四类维度和币种结转本币、外币及数量，累计归零；快照标识及重复执行保护。原时钟版/试用限制按重写任务要求移除。

现金流项目方向：与 M03/M05 共用持久化约定 `attrs.cashflowDirection: inflow | outflow | internal`。流入/流出按生成行实际现金增减核验；内部转移在每张凭证内净额必须为零，不能由非内部行或另一张凭证抵销。缺失或未知方向会阻止生成，不回退到 `attrs.direction`、规则位置或项目名称。预览展示档案方向，方向变化须重新确认。现金流是流量分类，不参与四类辅助余额桶的结转基数。
