# 仓库进销存（成本会计）

- `w_cb_cpda/cpda_xg/tyzs`：产品维护、改号、停用、启用末级科目校验、零系数确认、明确集合的批量修改与两次确认删除；已发生存货科目禁止改动。支持编码、名称、拼音查找与 Excel 导入预览/导出。
- `w_cb_ckxz/qc`：独立仓库/车间，按仓库的原子期初替换、逐行导入校验、期初阶段和核算截止保护。
- 单据 Excel 导入使用统一模板列“产品编号、数量、单价（元）、含税口径（是/否）、说明”；含税口径必填，未知列、重复列、空值及错值明确报错。保存明细可“导出可回导明细”，保留原输入单价及含税口径。
- `w_ck_rk/rk1/ck/ck1/cx_rkd/cx_ckd`：真实头行、查询、复制草稿、上/下一张、独立仓库审核与撤销、导入/导出、打印。已保存单据生效。方向+仓库+单号唯一；自动编号需明确操作。事务内库存检查、revision、幂等请求和绑定版本的负库存确认。
- `ht1/ht2/w_cb_ck_copy`：独立采购合同、供应商、交期和人工执行状态，复制后重新输入合同号，带入来源入库草稿，保存合同不影响库存。
- `w_ck_kc/kc_hz/tz/tz00/tz1`、`w_cb_hzsj_sfc/sl_hzyeb/hzsj_rk/hzsj_ck`：当前数量、逐笔台账、期初/期间/结余、按产品/类别/科目汇总、原单穿透，入/出库默认价估算明确标记。
- `w_ck_xsmxz/xsmxz1`：仅销售出库的销售收入明细，成本未核算留空并保留状态。
- `w_cb_pdk/pdk_1`：月末账面快照、实盘/差异重开、覆盖/清差/删除确认；实盘不直接改库存。
- `w_cb_tzxx`：账套内编号规则及刷新偏好，DataTable 列宽记忆/确认恢复和 Excel 导出，使用 `@caiwu/print`。

数量 API 为十进制字符串，数据库 `_e6` 为整数；金额 `_cents` 为整数分。产品 ID 不随编号变化。`inventory_control` 保留核算截止日期/期间/批次和期初锁；头行保留核算状态/批次/期间、审核人/时间、来源类型/ID、凭证关联和 revision；出库行 `outbound_cost_cents`、`unit_cost` 默认 null，默认状态 `uncalculated`。W2-01 可在后续授权下读取期初、入库金额和库存数量并写核算字段。
