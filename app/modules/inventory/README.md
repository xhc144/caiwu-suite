另据发票 `w_fp_pz_ckd` 的出库生成规则，提供发票专用出库预览和事务保存：逐行保留税率和金额，确认新增产品、负库存或替换原单后整批办理。发票来源唯一，普通库存入口不能改删，收入凭证由发票业务办理。

普通保存、删除、调拨、反冲和多单转入接入库存事务，权限和期间约束在服务端复核；多单预览还绑定账套、操作员、库存及档案版本。数量以十进制字符串传输、以六位小数整数存储，金额以整数分计算。文件交换只恢复业务头行和关联，转入为未审核单据；凭证和正式核算结果由目标账套重新处理，已有同号单据不覆盖。

合同来源按已保存且未被整单反冲的入库数量累计；入库修改扣回本单，删除恢复余额。恢复的额度已被后续入库使用时，须先处理后续入库才能撤销反冲。合同文件只迁移合同头行，不迁移来源入库和履约历史。普通单据保存后不可改换来源，被复制引用的来源单据不能先删。多单转入按完整反冲对的净履约合并检查同合同数量，已满合同也可迁入净零历史；原始数量、金额与来源保留，保存后重新核对实际头行、关联及履约。按来源和可用库存安排执行次序，反向来源必须保留反冲关联，不能把发票来源当普通复制来源。

合同同产品累计数量及交换文件金额总计均检查允许范围；超过范围时拒绝保存或转出，不生成无法履约、无法回导的数据。

反冲默认采用相反出入库方向，逐行恢复或冲减原数量。入库反冲沿用原输入单价、税率及含税口径；出库反冲必须逐行确认退回入库单价，已核算单位成本仅作为填写参考，不自动把销售价当库存成本。反冲出库的正式成本仍由本期核算确定，原会计凭证不自动冲销。静态资料只显示反冲入口、复制窗口及重复号校验，未包含原事件的完整计价算法；以上为明确呈现给操作者的默认处理。

期初直接金额口径要求正数量能够以六位反算单价回算原金额；零数量反算、负数量、负金额和不能保持原金额的尾差目前拒绝保存。不会擅自调整数量、改金额或分摊尾差。

仍未提供的原版外围功能：

- 仓库级操作员授权；产品五笔检索、任意字段条件查询和全套旧快捷键。产品批改仅列出实际档案字段，不新增原表中不存在的日期型字段。
- 销售合同、生产与连锁计划及其独立履约。
- 批号、全部原版列、零售价口径和特殊打印版式；Windows 实际打印仍需桌面环境核对。
- 直接编辑盘点单价／金额和独立调价，需与成本核算共享实际金额契约。
- 受保护的破坏性初始化、历史税率修复和数据整理，需先有可用的备份及恢复入口。
- 旧版凭证文件转入、先进先出计价。成本利润及凭证生成页面由成本核算功能提供，不以本模块销售明细替代。
- 红字发票退货转库明确拒绝；库存文件不能单独迁移发票来源单。发票页面和共享层窄身份桥须由各自模块接入，本模块已注册专用预览及保存能力。
