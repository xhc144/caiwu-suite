# 凭证序时簿

功能清单：

- `w_pz_pzxsb / w_pz_see / w_pz_zhcx`：期间、日期、号段、状态、科目、摘要、制单人和综合条件查询，分页与完整范围总数；金额按元输入，旧分值链接、刷新和历史查询保持原义。制单人按姓名和账号搜索，历史停用账号可查，仅返回安全字段。
- `w_pz_tjsh`：本人不得审核自己的凭证；有权限的另一操作员可审核或取消审核。逐项成功/跳过原因、现金流量确认和权限、来源、期间、作废及版本复核均保留，整批事务提交。
- `w_pzedit_fc`：逐行明确选择红冲后的合法现金流量项目；按借方减贷方的实际正负核验，内部转移单独精确配平。取消不生成，过期预览、撤权、来源或项目变化拒绝，同次确认可幂等重放。
- `w_pzedit_copy / w_pz_tjdel / w_pz_bhzl / w_pz_plxg`：复制、插入、删除、作废、编号整理和批量改期/类型，预览影响后再次确认；来源及已审过账保护。
- `w_pz_get`：Excel 与凭证转出文件导入、字段映射和逐凭证结果，歧义映射阻止，报错后可修正重试，覆盖需独立权限和版本确认。
- `w_pz_ttsee / w_pz_kmhz / w_pz_kmhz1`：丁字账和科目汇总，当前范围打印与导出，大额金额无损输出，超范围合计明确阻止。
