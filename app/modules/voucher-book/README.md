## 未完成项与原因

- 原 PR76 的公共编号模式（计算机编号同月同类型且只删最高号）及“不能改别人凭证”策略仍无 core 契约；批量改日期/类型涉及这两项原规则仍待共享接入，不私建参数、不改账套模式。批量改制单人同上。
- 原版交叉查询、综合查询任意列/去重展示/逻辑组合/排列顺序、查询结果专用另存/打印未实现；主序时簿和五字段条件查询不能代替完整功能。
- 原版汇总的会计主管/审核人选择与签名、丁字账原币专用展示/格式、报表应用内预览/打印设置及重选专用对话框未实现；当前提供筛选表单重选、系统打印与 Excel。Windows 打印机和桌面实机未验证。
- 原版全局“浏览查询/凭证审核/反审核”独立菜单、操作易人、连续/合并打印、辅助交叉查询入口尚未全部接齐；现有序时簿内按钮可操作审核/取消审核。
- 原版导入的时钟版截至日期/授权限制没有公共契约；不存在或非明细科目当前逐凭证拒绝，不自动替换为默认科目，仍缺有明确确认的科目编码修正映射。原 PB/SQL Anywhere 二进制/旧导出文件未解析，v1 文件并非原格式兼容。
- 原 PR76 的窗口格式手动保存/恢复、文件替换确认仍未实现；列表列宽自动记住不能替代整个窗口布局。
- 原 PR76 记录的路由/标签同步依赖共享壳（原 M20/PR75）。本次以指定 main 实测，不改壳，不以先前旧壳失败记录宣称当前已修复；历史 CI 付款/spending-limit 阻塞未付费处理。
- 通用 Excel 导出的大额金额精度仍需共享 owner 提供无损输出契约；本模块已局部保护，不修改共享导出器。
- 处理清单为执行时快照，页面显示最近一次完成结果；刷新后的历史结果浏览/长期批次管理尚无入口。只新增本模块代码、测试和此清单，未改共享层、依赖锁或原安装资源。
