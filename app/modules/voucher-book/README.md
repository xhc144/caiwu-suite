# 凭证管理（voucher-book）

| 原版窗口或菜单 | 功能 |
| --- | --- |
| `w_pz_pzxsb` / `w_pz_see` / `w_pz_pzxsb_see` | 序时簿、期间及日期、类型号段、状态、科目含下级、整数分金额范围、摘要、制单人、作废筛选；完整范围总数与分页、地址栏条件、刷新及前后退；查询导航保持同一筛选表单，保留后续输入并提示未提交条件，历史与外部条件同步；展开分录、来源和只读原因。 |
| 序时簿操作菜单 | 新增 Ctrl+N、复制 Ctrl+T、删除 Delete、单张审核 F4、刷新 F5、定位查询 Ctrl+Q；编辑和查看跳凭证录入路由，科目双击跳明细账路由。 |
| `w_pz_tjsh` | 稳定 ID 集合的批量审核、取消审核；本人、非候选、作废、闭账逐项说明；合格集合一次变更；现金流量缺失或无方向元数据必须另行确认，非法项目和明确方向冲突阻止。 |
| `w_pz_tjdel` | 删除预览、断号区间展示、确认；可明确选择删除后整理，并在同一事务执行；审核、过账、期间和来源保护；保留计算机编号删除策略函数，当前执行 core 的允许断号语义。 |
| 作废 / 取消作废 | 危险操作预览确认，保留编号与分录；草稿、过账、闭账及来源保护；默认不进汇总与丁字账。 |
| 插入菜单 | 从所选凭证取得可编辑的完整平衡分录；预览目标号及后续号加一；明确确认打印影响后原子腾号并创建待审核凭证。 |
| `w_pzedit_copy` | 按列表原件复制，选择目标日期和类型；新手工待审核凭证、新编号和当前制单人；不复制来源、审核记账人或冲销链；完整调用保存校验。 |
| `w_pzedit_fc` | 同向负数红字冲销，借贷、原币和数量取反，汇率单价保留；本地来源页显示双向关系；请求幂等，并发冲销使旧预览失效，再次冲销必须重新预览。 |
| `w_pz_bhzl` | 全期间同类型编号前后映射；按旧号或日期、旧号、ID稳定排序；作废参与、草稿不编号；事务重读完整编号集合，记录映射日志。 |
| `w_pz_kmhz` / `w_pz_kmhz1` | 期间、类型、号段、全部/未过账/已过账；一级或明细科目汇总；原币按币种分别展开；仅计分录发生，不含期初；导出当前范围。 |
| `w_pz_ttsee` | 必须选科目，借贷两侧日期、字号、摘要、金额和合计；无单据提示、凭证穿透、同范围导出。 |
| `w_pz_get` / 导入导出 / 转入转出 | 中文表头 v1 Excel 和版本化结构文本，保留科目及辅助编码、外币汇率、数量单价、结算方式、票号、业务日期、附单数与备注；字段映射、范围、目标日和类型、保留原日、编号策略、逐凭证错误清单；可明确选择仅合法集合；超过100项错误禁止写入；待审核覆盖有独立权限、revision清单和再次确认，整批事务写入。 |
| `w_pz_zhcx` | 可视条件编辑器，白名单日期、编号、金额、摘要、制单人名称与操作符；类型错误阻止查询，不忽略条件。 |
| `w_pz_plxg` | 批量修改日期或类型，可保留原日；预览编号和期间变化，再次确认；状态、作废、来源、双期间和revision保护；不改账套编号模式。 |

## 未完成项

- 地址栏条件及前后退依赖共享壳正确同步各标签页的路由上下文，并修复 `TitleOnMount` 更新循环（M20 / PR75）。本模块使用路由查询参数，不拦截历史事件或刷新页面；W0 壳独立组合仍有该共享问题。
- W0 没有公共编号模式及“不能改别人凭证”策略契约。未伪造 M01 参数或建立私有副本；计算机编号只能删同月同类型最高号的策略已保留，需公共契约接入后启用。
- 原版批量重指定制单人未提供。core 的凭证写入口不支持变更制单人，本模块没有直接写核心表的替代接口。
- 原版窗口格式的手动保存/恢复菜单未提供；现有列表列宽由通用表格自动记住。文件重名处理交由浏览器下载保存流程。
- 不解析原 PB / SQL Anywhere 二进制；转入转出使用本模块 v1 结构文本。完整录入编辑器、过账结账、基础档案、用户管理和打印按模块分工由 M05/M07/M03/M17/M19 提供。
