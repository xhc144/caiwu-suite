规则逐项：

- `w_fx_copy` 账套必选（含切换账套）、编码重复、源表必选、表名必填：未实现，随自定义表切片保留。
- `w_fx_def` 未保存退出、存盘失败保稿、错误输入阻止：未实现，当前无自定义编辑页。
- `w_fx_demo` 基数零、缺右括号、除零、两处缺运算符规则：未实现于自定义公式；基础科目占比零分母已有明确不可计算。
- `w_fx_demo_tx` 彩色打印确认：未实现，独立图形打印尚未接入。
- `w_fx_km` / `w_fx_nd` / `w_fx_yd` 不存在科目：已实现，服务端拒绝；`w_fx_main` 建立失败、删除确认：未实现。
- `w_fx_nd_1` / `w_fx_yd_1` 未保存退出、存盘失败：原可编辑分析表未实现，不能用配置保存替代这两条规则。
- `w_ht_htda` 未保存退出、存盘失败、错误输入、本人反审核、删除失败回滚、已用禁删、删除确认：本次实现，真实账套单测及独立 E2E；未保存保护覆盖抽屉、刷新、显式关闭，跨模块菜单切换保留隐藏标签输入，壳内部自动淘汰仍待共享 owner。
- 凭证合同相关规则（原 `w_pz_pzedit*`）：不存在合同/错误客供/错误借贷方向本次在显式关联时拒绝，现金银行按实际科目标志验证；票据、其它货币资金和来源凭证的合同录入校验尚未实现，不用摘要、编号或科目名称猜关联。
- 合同导入中的重复编号覆盖、成功/失败条数反馈：未实现；`m_work_fx_def` 全部分析/另存/增改删/移动/函数菜单和 `m_work_fx_demo` 方法/打开/另存/增删/图形菜单尚待自定义分析切片。`m_work_ht_zw` 本次实现审核/刷新/保存/新增/删除，其他导入/拷加/重取/定位/移动/档案打印另存与快捷键保留未实现。
- `m_work_fx_nd` 重选/另存/图形/数据打印、`m_work_fx_zl` 分析/账册/另存/打印已有页面操作；原 Ctrl+P 等全部快捷键映射未补齐。`m_report_r` 查询/另存/打印本次可用；其隐藏上/下/左/右移、放大/缩小/设置与报告专用退出未实现，标签由壳关闭。

合同口径与边界：期初收付款仅代表账套启用日前累计；本期只取期间内显式关联分录，累计为期初加截至截止日的分录，未完成允许负数。金额统一为本位币整数分。收付款科目需启用客供核算，不能推断无客供分录。关联要求已审核合同、已过账未作废手工凭证、匹配科目/客供/正向金额；一条分录只能关联一个合同。来源模块凭证仍由其 owner 控制。关联行的 RESTRICT 外键保护原分录；反过账/作废后报告明确报错，需恢复状态或明确取消关联，不能输出不完整金额。

共享需求：core 需提供合同引用的友好业务锁预检（当前修改/删除被引用分录由外键安全拒绝，提示仍是通用数据库错误），凭证编辑需合同查找/关联入口；跨账套分析复制需受控源账套读取；明细账需识别 `cutoff/includeUnposted/excludeClosingKind/currency`。本任务不改共享层、不依赖同波页面造数。没有重新解析安装资源、读取真实账套或旧 C# 目录。原账套导入、旧四位小数金额的兼容转换、三产品 Windows/DPI/实体打印验收均仍未实现或未验证。

分析 Excel 保留数值或精确文本：超过9999999999999.99元时以两位小数文本及文本格式保存。账龄来源表保留日期来源、原始金额和剩余敞口；业务日期账龄不等于逾期账龄。原始到期日缺失时始终显示未知。
