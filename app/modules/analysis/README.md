# 财务分析（analysis）

功能：

- `w_fx_zl` 账龄分析：按客供、可扩展项目/部门/个人；凭证日期截止、业务日期起龄、逐笔 FIFO；可配置并保存连续天数区间；期初未分龄、未来业务日期、反向余额单列；币种分开核销，金额折合本位币；同截止日总账核对、核销明细、Excel、打印和账簿/凭证链接。
- `w_fx_km`、`w_fx_nd(_1)`、`w_fx_yd(_1)`：所选科目的年度 1–12 月、月度借贷发生额/余额，年累计、月均和比例；经营口径明确排除损益结转标记 `pnl`，原始总账口径保留；零分母显示无法计算；启用前月份不补零。工作台六类科目入口可配置并保存，不预设制度科目号。
- `w_fx_txxz`、`w_fx_demo_tx`：同一查询结果的柱图、折线图、非负数饼图；表格始终可读。科目分析支持 Excel、打印、列宽记忆和带口径的明细账链接。

未实现：

- `w_fx_main`、`w_fx_copy`、`w_fx_def`、`w_fx_demo` 自定义分析表的增加/复制/删除、源表选择/编码唯一/名称非空、项目与小计、安全白名单 AST 算术/引用/科目指标、旧函数、删除和未保存离开确认、公式语法及除零校验；相应规则测试尚未实现。
- `w_fx_1` 结构分析、上年同期/指定基期比较、月/季/年趋势、绝对/定基/环比及相应图表、启用前基期说明；当前仅有基础科目年度/月度趋势。
- `w_ht_htda`、`w_ht_htda_nr` 合同档案持久化、唯一合同号、名称/客供/签订日期/收付款类型/金额/期初收付/说明/备注/审核人状态、本人取消审核、已用禁删、删除及未保存确认、并发保护与保存事务；相应规则测试尚未实现。
- `w_ht_httj`、`w_ht_pz` 合同账款筛选查询、本期/累计收付/未完成金额、真实分录明确关联/取消、科目/客供/状态/金额校验、合同说明和凭证钻取；合同关联表及相关权限、事务、导出打印、完整 E2E 尚未实现。
