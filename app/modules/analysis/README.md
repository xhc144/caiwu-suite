# 财务分析与合同

功能依据：三产品 `docs/original-analysis/products/*/main/menus.md`、`windows/fx.md`、`windows/ht.md`、`rules.md`，以及 `data/tables.md` 中 `fx_ml`、`fx_dy`。以下为当前源码行为。

- 科目年度/月度分析（`w_fx_km`、`w_fx_nd`、`w_fx_yd`）：选择任意科目，查看发生额、余额、累计、月均和占比；六类便捷入口可配置，支持含未过账、图形、Excel、打印与明细账跳转。
- 分析结果编辑保存（`w_fx_nd_1`、`w_fx_yd_1`）：通过“编辑并保存结果”修改月数，累计、月均和比例自动重算；取数原值独立保留，保存后可从“已保存分析结果”重开、继续编辑、另存、导出、打印或确认删除。
- 自定义分析表（`w_fx_main`、`w_fx_copy`、`w_fx_def`）：新增、同账套复制、唯一三位编号、名称及公式校验；项目可增删、复制、上下移动、设置单位与小计，项目编号稳定，支持 Ctrl+S。
- 自定义计算（`w_fx_demo`、`w_fx_demo_open`）：按最多36个月真实取数，支持借方、贷方、余额、期初、年初、累计借方、累计贷方及项目引用、四则运算；有函数指南和按科目追加函数的向导，拒绝无效科目、缺括号、缺运算符、除零、循环引用与超范围结果。计算结果可手工调整、保存重开及导出打印。
- 定义及结果离开保护（`w_fx_def`、`w_fx_nd_1`、`w_fx_yd_1`）：关闭编辑器可保存、放弃或继续编辑，接入标签关闭、切账、退出的统一未保存检查；保存请求失败或版本冲突保留当前输入。定义、结果与操作日志同事务保存。
- 结果保存受查看和维护权限约束，服务端在写事务中逐月检查期间；已结账或已年结期间不能修改、保存或删除分析结果。定义属于账套配置，独立于期间。
- 账龄分析（`w_fx_zl`）：连续区间持久化、客供及项目/部门/个人分组、币种分别 FIFO、期初未分龄/未来日期/反向余额单列、总账核对、核销明细、Excel/打印与凭证链接。
- 图形分析（`w_fx_txxz`、`w_fx_demo_tx`）：柱图、折线、非负饼图与可读数据表；结果稿图形展示第一个金额项目。
- 合同档案（`w_ht_htda`、`w_ht_htda_nr`）：保留合同号唯一、真实增改删、收付款类型、期初收付、客供科目校验、说明备注、审核/本人反审核、已用禁删、删除确认、版本与事务保护。
- 合同账款（`w_ht_httj`、`w_ht_pz`）：保留日期/客供/类型查询、显式已过账现金银行整条分录关联、本期/累计/未完成、取消关联确认、Excel/打印与来源读取权限边界。

计算约定：金额落库为整数分，公式数字与科目数按元进行十进制运算，最终四舍五入至两位。余额借正贷负；经营口径排除报告年度内标记为损益结转的凭证。年初取该年首个启用月份的总账期初，累计发生额含期初本年累计。小计由公式明确填写，避免重复汇总；自定义末期数取最后一月。手工调整只改分析稿，不回写总账，也不自动重算其他项目公式，小计须一并调整。首次保存前来源变化会拒绝保存并保留输入；已保存稿保留当时快照。

Excel 金额超过数值精度范围时使用精确两位小数文本。原始到期日缺失时明确显示未知，不将业务日期账龄当作逾期账龄。
