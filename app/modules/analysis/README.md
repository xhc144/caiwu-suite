# 财务分析与合同

功能依据：三产品 `docs/original-analysis/products/*/main/menus.md`、`windows/fx.md`、`windows/ht.md`、`windows/bb.md`、`rules.md`，以及 `data/tables.md` 的 `fx_ml`、`fx_dy` 与 `json/datawindows.json`。

- 科目年度/月度分析（`w_fx_km`、`w_fx_nd`、`w_fx_yd`）：任意科目的发生额、余额、累计、月均和占比，支持包含未过账、六类可配置便捷入口、图形、Excel、打印与明细账跳转。
- 自定义分析表（`w_fx_main`、`w_fx_copy`、`w_fx_def`）：新增、删除确认、同账套复制及跨账套复制；来源账套独立验证操作员及查看权限，目标验证维护权限、唯一三位编号、科目、币种、辅助编码与源版本，只复制定义。
- 定义项目可增删、复制、上下移动、设置单位和小计，项目编号及引用稳定，删除后新增不重用旧引用编号；提供函数指南及科目、数量、币种、辅助对象向导，支持Ctrl+S保存、Ctrl+A增加、Ctrl+K复制、Ctrl+D确认删除、首末及上下记录选择、Ctrl+P打印定义稿和另存定义Excel。
- 自定义计算（`w_fx_demo`、`w_fx_demo_open`）：最多36个月真实取数，支持借方、贷方、余额、期初、年初、累计借方、累计贷方、项目引用及四则运算；支持来源明确的 S数量、W外币、F辅助参数，拒绝无效编码、缺括号、缺运算符、除零、循环引用和数值越界。
- 结构、比较与趋势（`w_fx_1`）：指定基数项目的结构占比、上年同期或指定基期的金额/差额/发展速度/增长率，月季年绝对数、定基及环比趋势，配套图形、Excel和打印；季年取数明确选择末期值或逐月合计，不自动累加余额与比率。
- 分析结果编辑保存（`w_fx_nd_1`、`w_fx_yd_1`、`w_fx_demo`）：调整、保存、重开、另存、导出和确认删除；独立保留取数原值，累计、月均和占比随调整重算，数量或数值项目可保存六位小数。大分析稿通过请求体导出，避免地址长度限制。
- 定义及结果离开保护：关闭、切账和退出接入统一保存检查；失败与版本冲突保留输入，本机恢复副本按账套和操作员隔离。来源或定义变化后旧稿仍可导出，不会直接覆盖新版本，保存期间不能恢复其他草稿。
- 定义属于账套配置；结果保存、修改和删除在事务中检查相应期间，已结账或已年结期间不允许写入；操作日志和数据一起保存。
- 账龄分析（`w_fx_zl`）：连续区间与原版15桶预设、默认保存重开、客供及项目/部门/个人分组、币种分别FIFO、期初未分龄/未来日期/反向余额单列、总账核对、核销明细、Excel/打印与凭证跳转；支持列宽微调/恢复、专用年份选择及闰日处理，Ctrl+P使用同一权限和数据打印。
- 图形分析（`w_fx_txxz`、`w_fx_demo_tx`）：柱图、折线和非负饼图，柱线坐标转换及恢复；独立条形图形打印含正负零轴、精确数据表、标题及期间，可选择彩色或黑白、取消打印；科目和结果页Ctrl+P进入当前图形选择，不抢隐藏标签的焦点。
- 合同档案（`w_ht_htda`、`w_ht_htda_nr`）：唯一合同号、真实增改删、拷加、双备注、说明、审核/本人反审核、已用禁删、版本保护；支持字段定位、首末上下条、重取、常用快捷键及档案独立Excel/打印。
- 合同档案导入：XLSX逐行预览、错误原因和成功/失败条数，覆盖须确认；已审核或已使用合同不允许覆盖，每条合同独立保存，错误行不影响其他行，预览后数据变化须重新预览。
- 合同草稿：统一离开守卫、保存失败恢复、版本变化阻止覆盖，保存等待期间禁用草稿恢复；恢复副本不包含来源账套登录口令。
- 合同账款（`w_ht_httj`、`w_ht_pz`）：签订及独立收付期间、客供、类型查询，显式关联已过账现金银行整条分录，计算本期/累计/未完成；可取消关联、钻取凭证，档案与收付明细可独立导出打印，来源拒读边界保留。

取数约定：金额以整数分保存并用Decimal运算，数量从六位小数字符串计算；外币只取指定币种，单个数量科目取数不混加不同单位。余额借正贷负；经营口径只排除报告年度启用后明确标记的损益结转，不编造启用前累计。启用前历史及不完整区间的发生额合计留空说明；有真实来源的末期值可读取，零基数不计算比例。年初取该年首个启用月份的真实期初。小计由公式明确填写；手工调整只改分析稿，不回写总账，也不自动重算其他项目公式。

Excel金额超出数值精度范围时用精确两位文本，六位数量使用精确文本。账龄首桶含当日0天，后续连续不重叠；原版31–61与61–90标签交叉处采用31–60、61–90。原始到期日缺失时明确显示未知，不将业务日期账龄视作逾期账龄。
