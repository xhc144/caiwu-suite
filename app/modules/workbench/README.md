# 工作台

功能清单：

- `w_main1`：显示当前账套、单位、制度和期间；按当前用户可读取范围统计待审核与待过账，排除草稿和作废，已审核未过账计入待过账。返回已有工作台标签时重新读取，待办带期间和状态跳转。
- 按产品及权限展示功能、常用和最近功能；原工作台的凭证、期末处理、账簿、档案、备份和报表入口映射到已有页面，没有对应功能时明确说明。
- 搜索功能、凭证字号与摘要、科目及客供等资料，使用来源读取权限过滤；个人收藏、首次引导、产品切换和操作日志。
- `w_frame / w_main1`：沿用壳的搜索、帮助、界面偏好、标签与会话隔离；管理员入口按真实身份授权。

未完成项：

- 未声明独立入口的辅助账簿、现金流量试算、自定义分析和合同等业务需由相应功能补齐；工作台不替代记账、结账或报表计算。
- 原全局计算器、屏幕打印、工具条配置、全部原快捷键和桌面原生缩放尚未补齐。标签页不模拟旧式窗口级联；不接入原厂加密狗、注册和云服务。
