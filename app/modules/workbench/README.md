# 工作台（workbench）

- `w_main1`：当前账套/单位/制度/产品、按期间的真实待审核和待过账数（返回已打开标签时重新读取）、真实期间状态与未完成过账提示；待办、结账、余额、明细导航。
- 统一功能导航、常用/最近功能、原工作台三组入口对照；未加载或无权入口不提供业务操作。
- 全局搜索：功能、凭证号/分录摘要、科目、摘要库、客供；名称/编码/基础档案拼音查询，来源权限和产品过滤、防抖与条数限制。
- 壳提供 Ctrl+K、?、F1、Ctrl+F4、快捷键总表、标签 URL/历史同步、会话缓存隔离、工作台改密会话检测、主题和网页缩放。标签忽略尾斜杠并保留查询参数；历史返回会重建已关闭页面，迟到导航不关闭刚打开的搜索。
- 设置：切换产品前接入统一未保存检查，可保存、放弃或取消；授权事务切换账套产品并写日志，个人常用功能/首次引导记录；帮助和真实版本信息。

W2 对照范围：`qingsong/main/navigation.md` 的工作台全部有效入口、`menus.md` 默认主菜单及其继承项、`windows/misc.md` 的 `w_frame/w_main1`、`rules.md` 同名规则。以下“入口”只表示导航；业务实现及其未实现项仍由对应模块负责，不据按钮判断完成。
