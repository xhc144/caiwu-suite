# 工作台（workbench）

- `w_main1`：当前账套/单位/制度/产品、按期间的真实待审核和待过账数、真实期间状态与未完成过账提示；待办、结账、余额、明细导航。
- 统一功能导航、常用/最近功能、原工作台三组入口对照；未加载或无权入口不提供业务操作。
- 全局搜索：功能、凭证号/分录摘要、科目、摘要库、客供；名称/编码/基础档案拼音查询，来源权限和产品过滤、防抖与条数限制。
- 壳提供 Ctrl+K、?、F1、Ctrl+F4、快捷键总表、标签 URL/历史同步、会话缓存隔离、工作台改密会话检测、主题和网页缩放。
- 设置：授权事务切换账套产品、写日志，个人常用功能/首次引导记录；帮助和真实版本信息。

未完成：业务模块尚未合入的实际操作；统一路由/实体读取权限元数据、统一表单 dirty/关闭协议、任意模块的 window 级快捷键优先级、Electron 原生缩放需共享层接入。普通用户嵌套路由无明确菜单映射时拒绝访问；实体只接受已加载来源的明确 `.view` 入口权限。结账的断号/试算/损益检查由期末模块提供，工作台不虚构完成比例。浏览器静态注册暂不支持临时来源测试模块，来源授权由服务端集成测试覆盖。
