未实现项（保留原目标及 PR #60 遗留）：

- 已接入统一异步保存/放弃/取消：关闭标签、关闭所有、同标签路由离开、切换账套及桌面退出只提示确有修改的页面；保存失败停留，保存期间的新编辑保留，存净后才放行。浏览器原生重载/关闭继续提醒并保留会话草稿；关闭期间尚未返回的保存请求必须先等待结果。
- 上表列出的总账/明细及上/下级切换、Ctrl+A/Ctrl+D、首末/上下记录移动仍缺记录焦点模型与交互；并未完成原快捷键全覆盖。
- 原查找窗的 F2/双击辅助账簿穿透、关闭期初后返回 `w_acini_wizard` 建账向导尚未对接；当前提供科目/辅助档案维护和期末处理路由入口。
- 原表 `nc`、`xmnc/dwnc/bmnc/grnc` 区分外币年初借贷、账前外币借贷、折合本位币及年初汇率。现有 core 只保存本位币余额/累计、单个外币启用余额和启用数量；**外币年初与账前外币累计的独立录入、年初汇率持久化、对应数量年初/累计口径尚未实现**。须由共享 owner 定义兼容字段和账簿/年结口径，本模块不能以汇率推算冒充原值。
- 损益清理目前仅处理本位币年初额；上述独立外币/数量口径齐备后仍需补齐相应清理规则和确认预览。
- 打印当前为 A4 横向明细报表；原版专用打印格式/套打、自定义列和页码设置、账套启用向导联动仍待完成。浏览器可经系统打印对话框另存 PDF；未宣称 Windows 物理打印机实机通过。
- Excel 每批限 5000 行、650KB，仅首个工作表；超限分片向导及多工作表选择未实现。

PR #60 所提壳同路径 location、标题回调及尾斜杠标签身份已在本次基线修复，现有壳回归覆盖；本模块保留即时筛选兼容逻辑，并修正自身路径比较。共享需求仍为 core 外币/数量年初及累计模型；仅共享 owner 修改。本模块无新依赖、核心迁移或跨模块 import。

本轮修正：保存返回同一事务内的记录版本，新增保存期间继续编辑可再次修改同一行；科目树仅汇总同币种外币及同单位数量，混合币种或单位明确显示不合计。
