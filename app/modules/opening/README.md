# 期初余额（M04）

| 原版窗口 / 菜单 | 已实现 |
| --- | --- |
| `w_xt_ye_nf` 选择年份 | 顶部年度、币种、数量及科目筛选同步 URL；拒绝开账前及未建立年度，提供期末处理入口。 |
| `w_xt_ye` 期初余额录入 | 按真实科目树汇总、末级明细录入；区分未录入与显式零；年初余额和启用余额分开，账前累计单独保存；本位币/外币/数量独立录入。 |
| `w_xt_xmnc` 项目、`w_xt_dwnc` 客供、`w_xt_bmnc` 部门、`w_xt_grnc` 个人期初 | 四个直接菜单及页内视图；真实档案校验、多维组合唯一；新增拒绝重复，修改检查原内容；父级/无辅助汇总不重复写入。 |
| `m_work_xt_01` / `m_work_xt_fznc` 分级汇总、存盘、另存、转入/导入、删除 | 自动汇总、Ctrl+S 保存；整年度 Excel 导出；逐行预览后单事务新增或覆盖，不删除文件之外的记录；删除确认、损益年初数预览及文字二次确认。 |
| 试算及写保护 | 年初、账前累计、启用余额及 core 期间试算；失衡可保存但不能锁定；定位当前科目；按权限手工锁定/解锁，所有实际写入口检查手工锁、同年过账、结账并记日志。 |
| 未保存处理 | 抽屉、顶部条件、常用菜单/标签关闭、F5/Ctrl+R/Ctrl+F4 提供保存/放弃/取消；失败留稿；账套内 sessionStorage 恢复刷新前输入。 |

未完成项：

- 壳尚无统一离开/关闭拦截 API。浏览器工具栏刷新/关闭使用原生留页提示并保留草稿，浏览器前进后退、程序自动关闭/淘汰标签及桌面退出尚不能统一提供三选确认。已有模块内保护不能替代全局生命周期接口。
- 原菜单的打印/打印预览、Ctrl+A/Ctrl+D 新增/删除、记录首末/上下移动快捷键、总账/明细级次快捷切换未实现；当前可展开/折叠科目树、定位筛选与导出 Excel。
- Excel 每批限 5000 行、650KB；尚无超限文件分片向导。只处理首个工作表。

共享壳在同路径参数更新时可能提供旧 location，本模块保留 `useUrlFilters` 写 URL 并即时同步本地筛选。尾斜杠入口可能由壳保留为另一标签；隐藏标签保留原输入。
