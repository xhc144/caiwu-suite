# 余额表

功能对照原版 `qingsong/main/windows/{zw,zc}.md`、`menus.md`、`rules.md` 与 `data/tables.md`。

| 原版窗口 | 可用功能 |
| --- | --- |
| `w_zw_ye/w_zw_ye_1` 汇总余额表 | 按期间、科目范围及未过账口径查询，显示真实科目树、借贷方向、逆向提示、本期及本年累计，支持展开、折叠、级次、末级和明细追查。 |
| `w_zw_wbye/w_zw_wbye_1` 外币余额表 | 逐币种显示原币及本位币期初、本期、期末和本年累计，保留红字及原币非零、本位币为零的行。 |
| `w_zw_slye/w_zw_slye_1` 数量余额表 | `/quantity` 按数量单位分别列示期初、本期、期末、本年累计和结余单价，同单位父科目与末级合计一致。 |
| `w_zw_fhye/w_zw_fhwbye/w_zw_fhslye` 辅助余额表 | 按项目、客供、部门或个人分表，起止范围可包含实际下级，按辅助级次汇总，可切换按辅助项或科目排列；币种、数量单位和精确辅助条件保持交集，空辅助项单列。 |
| `w_zw_fhye_1/_1_bak` 辅助层级 | 父项汇总可展开到实际分项并追查分项明细；父项包含下级、辅助级次和排列方式可按账套保存，地址条件优先。 |
| `w_zc_xjll/w_zc_xjll_1` 现金流量试算 | 左侧菜单、工作台及 `/cashflow` 均有真实入口，可选期间、项目及科目范围，核对现金银行期初、期末、净变动、已分配收付、内部互转和未分配差额。 |
| `w_zc_xjll_1` 项目及凭证明细 | 项目汇总显示本期及本年累计；明细可定位、排序、分页、首项/上移/下移/末项及键盘移动，点击凭证追查，选中后可到凭证序时簿审核、反审或删除。 |
| `w_zc_xjll_1` 刷新、格式和输出 | 包含未过账、较大数据刷新、保存格式和恢复格式均有确认；版本冲突保留当前视图；可另存 Excel、按项目批量转出，打印按核对、项目、凭证和科目分册，支持预览和连续打印。 |
| `m_work_zw_01/m_work_zw_01_fh` 定位 | 结果内按编码或名称定位，可找到折叠的下级科目，原查询范围合计保持不变。 |
| `w_zw_ye_kmxz` 打印科目 | 全部或指定显示科目、空选择阻止、独立预览、打印及 Ctrl+P；汇总、外币、数量和辅助余额使用完整列组分页，每页重复单位、期间及表头，可设置每页行数、起始页码和套打偏移，支持承前页和过次页。 |
| `w_zw_ye_ts` 跨年提示 | 查询跨年时说明余额连续承接，本年累计按结束期间所在年度列示。 |
| 展示设置存盘及退出规则 | 按账套保存、失败保稿、版本冲突不覆盖、取消确认；关闭标签、切换账套和桌面退出走统一保存保护，保存期间的新编辑继续保留，重开读取最新设置。 |

金额按本位币或各自原币列示，数量不跨单位合计。结余单价默认取期末本位币金额除以期末数量，四舍五入至六位小数；数量为零显示“—”。年中启用且缺少启用前原币、数量累计来源时，累计显示“—”及原因；现金流量累计明确标注启用后的起点。

现金流量按分录已存项目和流向归集，历史空流向不推断。内部互转不计入对外流入、流出；单个银行范围的互转净额可以非零，逐凭证配平检查仍覆盖完整凭证。项目选择只筛选项目汇总和明细，顶部核对始终包含所选科目全部项目。草稿、作废始终排除，勾选未过账后包含待审核和已审核凭证。

查询与导出使用同一事务快照。金额合计仅计算范围内末级科目一次，不受级次、展开、定位或只发生额显示影响。不同数量单位的父科目仍可显示金额，数量不混加。Excel 数量保留十进制文本；金额只有在不超出 15 位精度且能逐分回读时才输出数值，否则保留精确两位小数文本。指定科目打印不另列选中合计，避免父子重复；长名称拆行保留全文，金额和数量保持完整单元格，打印前检查实际排版。

仍未完成：

| 原版目标 | 当前边界 |
| --- | --- |
| 空辅助组及数量父科目钻取 | 明细取数尚不支持精确的空辅助项和数量单位筛选，保留余额但不提供会扩大范围的跳转。 |
| 现金流量超过明细上限 | 超过 5000 行需确认；任一查询或年累计超过共享取数的 200000 行上限时明确报错，不返回截断合计，仍需不受明细上限影响的汇总及分页契约。 |
| 极速导航竞态 | 普通前进后退和未保存设置保护已有回归；地址先改变、内容尚未提交时立即后退的共享壳竞态仍由壳处理，未补专门回归。 |

凭证的修改、取消审核、删除、编号策略及期间锁沿用既有凭证页面和服务端校验；本模块负责查询、追查和展示设置。查询、导出和格式保存分别检查查看、导出和设置权限。
