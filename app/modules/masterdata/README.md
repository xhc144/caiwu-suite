# 基础档案（M03）

- `w_xt_kmwh / _1 / _cfjc`：可展开科目树、编码/名称/拼音/助记码查询、全名整理、新增修改、核算标志和默认辅助项、停用、引用保护删除、最后下级影响确认与事务恢复末级。按账套级次校验，一级方向两次确认、反向及重名确认；货币资金范围取模板明确标志或人工确认的本账套层级。
- `w_xt_kmwh / w_xt_kmbm_get`：批量下级编码预览；科目 Excel 全核算属性与默认项导入导出，父子排序、逐行错误、预览不保存、确认整批事务、重复上传保留 ID。
- `w_xt_fhwh / w_xt_xmwh / w_xt_dwwh / _fj / w_xt_bmwh / w_xt_grwh / w_xt_xjwh / w_xt_wh`：五类档案直接写入 core，分类层级、分级规则、编号修改、停用与引用保护、拼音搜索及 Excel。客供角色、简称、联系和财税字段；现金流量方向写入 `attrs.cashflowDirection`，旧项目显示未设置方向。编辑取消/刷新有保存、放弃、继续选项，浏览器重载有原生保护。
- `w_xt_pzlx / _zj / w_xt_jslb / w_xt_fbwh / _1 / w_xt_zy`：凭证类型代码/简称/全称、结算、币种和期间十进制汇率、汇兑损益科目、分类摘要及快捷检索词；保护本位币、已用记录与最后可用类别。凭证简称写 core `voucher_type.code` 供凭证头显示，独立管理代码关联在本模块表；摘要保留 core 使用次数。

未实现：已使用末级增加下级并转移余额；带下级科目编码及核算语义的整树迁移；凭证类型借方必有、贷方必有、凭证必有/必无科目约束执行器；跨账套转入、原版 TXT/DBF、档案打印。摘要快捷词可查询，未注册全局键盘动作。任意浏览器后退或壳强制关闭的统一未存盘守卫仍需共享层钩子；当前覆盖抽屉取消/刷新、Ctrl+F4、F5/Ctrl+R 和浏览器原生关闭保护。汇兑损益科目暂为本模块配置，尚无 core 共享读取契约；不改变本位币，不宣称支持 CNY 以外的本位币核算。单次 Excel 最多 5000 行、675KB。
