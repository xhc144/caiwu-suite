入口：`/m/print-settings/preview?voucherId=…`，或 `?from=202601&to=202601&ids=3,1,2`。账册：`?mode=ledger&queried=1&account=1001,6603&kind=detail&from=202601&to=202601`；自动科目选择为 `accountScope=all/first/leaf`。特殊格式：`/m/print-settings/formats?voucherId=…`。

`@caiwu/print` 保留 W0 接口及纯数据构建函数；`PrintPage.account/pageNumber` 为可选增量，`runPrintBatch` 新增 `pause: 'account'`。旧 `ledgerBook` 仍返回模型数组，新 `ledgerBatch` 返回 `{ models, skipped }`。所有输出继续使用白名单、转义、CSP、sandbox、排版 preflight、作业锁与 `afterprint` 清理；测试在事件中捕获 HTML，不能依赖打印后 iframe 留存。源凭证只读，不改变来源锁；设置与日志在同一真实事务保存，不覆盖既有备份。

未完成（含 PR71 保留项）：任意单元格/跨表函数、公式向导和复杂合并、逐行逐列尺寸及财务取数模板；授权跨账套复制、旧格式文件导入/解析；数量/外币/多栏/辅助/增值税/现金流量专用完整格式；原版专用凭证纸的命名及确切尺寸待核（现有自定义毫米输入，不能以 A5/B5 代替原版型号）；字体不自动变小选项；合并同页凭证逐张暂停；标尺及其余菜单缺项见表；壳标签关闭/关闭所有的未保存拦截；Windows 打印机、安装/升级及桌面 PDF 自定义纸张联调。需 M20 的异步关闭守卫、M21 核对 `preferCSSPageSize` 与打印缩放；本切片无需 core 新接口。

浏览器 PDF 在系统对话框选择“另存为 PDF”；W0 `print(): Promise<void>` 不能区分物理打印完成/取消，页面仅报告已提交页数。Linux 真实 PDF 的页数、宽高、文字及边界检查不代表 Windows 实机完成。
