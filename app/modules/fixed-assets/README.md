# 固定资产

适用于民非企、成本会计。功能对照 `docs/original-analysis/products/minfeiqi/main/windows/zcgl.md`、`zjgl.md`、`zc.md`、对应 `menus.md` / `rules.md`，资产和部门结构对照 `data/tables.md`。

## 可用功能

- 类别、用途、状态、注销原因：新增、修改、停用；科目、残值率校验；被使用的档案不能删除（`w_zc_sblb`、`w_zc_sbyt`、`w_zc_sbzt`、`w_zc_sbzx`）。
- 部门：与账套基础档案共用，支持新增、修改、停用、启用；保留稳定关联，修改使用版本检查。删除先列出引用，资产卡片、折旧记录以及账套其他引用都会阻止删除（`w_zc_sydw_bak`）。停用部门不能分配给新增或其他资产；原部门不变时仍可维护原卡片名称等资料。
- 资产台账：筛选、含注销、查看、新增、复制、修改、删除及 Excel 导出；改编号须确认，已有折旧和调整时保护计算参数及分配维度（`w_zc_zcgl`、`w_zcgl_kp`）。
- 附属设备：随卡片事务保存，取消不写入；编号唯一，数量与单价按十进制精确计算（`w_zcgl_kp_fssb`）。
- 期初导入：双工作表 XLSX 模板、主卡片与附属设备预览、入库、导出回导，兼容旧单表；相同重导跳过，差异拒绝覆盖；坏文件、过期预览不能继续确认。预览及入库事务检查期初锁、启用月份结账及年结（`w_xt_kgzb_zc`）。
- 计提折旧：平均年限法、工作量法，月工作量录入，预览后确认，缺项明确跳过，累计上限、尾差及重复计提保护（`w_zjjs`）。
- 折旧凭证：科目及凭证类型设置、分录预览、生成、删除与来源跳转；审核和过账后保护来源。删除凭证、取消折旧和撤销注销均展示凭证删除及编号重排影响，确认后事务复核（`w_pz_build`、`w_zc_qxfz`）。
- 原值调整与注销：调整链查询、差异确认、原值下限、逆序撤销；注销日期与折旧检查，可选清理凭证，历史保留（`w_zcgl_yztz`、`w_zcgl_delete`）。
- 折旧查询与分布：期间、资产、部门、类别、用途、零折旧筛选；编码、名称、折旧额、使用日期最多 20 条交集条件，金额按元输入，旧链接兼容，Excel、打印、合计和确认列宽保存（`w_zjgl`、`w_zjgl_cx`、`w_zjgl_fb`）。
- 资产报表：资产明细账、资产清单、附属设备表、到期清单、年度增减清单、资产分布表和台账；按历史截止日取数，支持 Excel 和打印（`w_zcgl_prtmxz`、`w_zcgl_fb`、`w_zcgl_nd`、`w_print_tz`）。
- 资产标签：88×51mm，设备编号筛选、全部或序号闭区间、单色或彩色、逐页缩放预览、打印与自包含 HTML 文件输出共用版面。序号按当前截止日及编号筛选后的设备编号升序从 1 编排，筛选变化会重新编号；并非设备编号或数据库记录 ID（`w_zcgl_label`）。
- 统一置数：先筛选并预览规格、单位、购置日期、未折旧年限、编号补零；锁定及编号冲突逐项列出，字段长度等卡片约束仍生效（`w_zcgl_zs`）。
- 编辑保护：卡片及附属设备、基础档案、部门、调整及注销、月工作量、凭证设置、期初待导入数据、统一置数接入未保存提醒；关闭、同标签离开、关闭所有、切换账套等使用统一保存流程。失败保留输入，可修正重试；重复点击合并提交，保存期间的新编辑继续保留。标签与查询在筛选编辑、加载或失败时不沿用旧结果输出。

## 校验约定

- 编号及必填资料校验在服务端重复执行；金额按分保存，数量最多六位小数。低于 30 个月的使用年限须复核。附属设备与主卡片保存失败全部回滚。
- 使用当月不提、次月开始计提；现仅实现方法 1 平均年限法和方法 2 工作量法，其他方法尚未从静态资料核实，不推断公式。
- 取消按最后计提月逆序进行，已有后续调整或注销时不能跳过；期间、年度、来源凭证权限与状态在事务内复核。
- 期初 XLSX 只承载卡片及期初累计数，不含完整调整、注销和凭证历史，不能替代整账备份。
