规则清单（已有实现及本次导入共用服务端校验）：

- 类别/用途：非明细、停用科目不可选；四类档案编码必填/唯一、被引用不可删除、删除确认、失败回滚。部门只实现编码必填及新增；部门删除规则待 core 服务。
- 卡片：编号、名称、状态、类别、方法、用途、使用日期、正原值及平均年限法年限必填；编号重复拒绝，两处改编号确认统一为稳定 ID 与确认字段；少于 30 月须复核。类别/状态/用途/部门缺失给处理入口。
- 卡片/附属设备：附属必填、同卡编号唯一、十进制金额；保存失败整单回滚；已折旧不可物理删除，未折旧删除须确认；含注销由筛选控制。本次双表使用文本列保护前零，兼容旧数字编号的纯零补齐格式；孤立/重复归属、坏标题、模板外数据、未知非空工作表、公式/错误单元格拒绝，重导不得清空旧附属。
- 折旧：原值低于累计与残值拒绝、工作量不得超剩余、缺工作量/缺年限须明确跳过、原值调整链错误阻止；来源月份/已关期间保护；生成凭证须确认；取消依 core 状态逆序处理。
- 原值调整/注销：链与卡片不一致先确认、删除调整确认；注销不得早于已提月份，并明确选择是否生成清理凭证；审核/过账来源禁止逆操作。
- 报表：无减少/无附属明确空态；无记录不打印/导出。查询条件错误、非字符使用含有、非数字/非法日期/未知字段拒绝，不忽略条件；列宽保存/恢复均确认。原版大数据刷新/包含所有单据的逐次确认尚未逐项复刻。
- 初始化：服务端仍拒绝破坏性重置，普通开通/导入保留旧数据；原重置密码与清空确认流程待完整备份/恢复保护后实现。按使用日期重写累计折旧仍未实现。
