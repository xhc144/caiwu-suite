# 固定资产（M15）

仅民非企、成本产品启用；菜单统一位于固定资产分组。

- `w_zc_sblb/sbyt/sbzt/sbzx`：类别、用途、状态、注销原因维护，科目校验、编码唯一、引用删除保护及停用。`w_zc_sydw`：读取、新增 core 部门。
- `w_zc_zcgl`、`w_zcgl_kp/kp_fssb`：筛选、查看、新增、复制、修改、编号确认、附属设备、事务保存；累计数、净值与 Excel 导出。
- `w_zjjs`、`w_zc_qxfz`：平均年限法、工作量法（码 2），月度预览、缺项确认跳过、尾差、逆序撤销、工作量恢复、幂等与期间保护。月工作量在计提页录入；注销前先完成适用月份折旧。
- `w_xt_kgzb_1_zc`、`w_pz_build`：科目/类型设置、分录预览、core 创建/删除来源凭证、原子关联、审核/过账锁与来源跳转。
- `w_zcgl_yztz/yztz_cx/delete`：原值调整链、差异确认、逆序删除、注销及撤销注销、可选清理凭证；既有来源保护与后续期间增量业务分开校验，历史凭证已过账后仍可在开放期间继续调整、折旧及注销。
- `w_zjgl/cx/fb/sj`：月度明细、白名单综合条件、零折旧、部门层级/类别编码前缀分布、合计、列宽确认保存/恢复。
- `m_frame_zc/m_work_zcgl` 报表：明细账、资产清单、附属设备、年度到期（含以前年度）、增加、减少、截止日分布、台账、范围标签；Excel 导出及现有 `@caiwu/print` 打印，标签为 88×51mm。
- `w_xt_kgzb_zc`：保留数据开通，Excel 模板、逐行预览、事务入库、相同重导跳过、期初导出。历史资产通过期初导入，新增资产不直接覆盖期初累计数。
- `w_zcgl_zs`：筛选预览后统一修改规格、单位、购置日期、未折旧年限、编号补零；锁定及冲突逐项跳过。
