# 固定资产

适用于民非企、成本会计。对照原版 `zcgl.md`、`zjgl.md`、`zc.md`、对应菜单与规则，以及 `zc_gdzc`、`zc_sbbd`、`zc_zcbdb` 等表。

## 可用功能

- 类别、用途、设备状态、注销原因和共用部门的维护；停用、版本检查、引用预览及确认删除，卡片、折旧与转移历史都保护被引用档案（`w_zc_sblb`、`w_zc_sbyt`、`w_zc_sbzt`、`w_zc_sbzx`、`w_zc_sydw_bak`）。
- 资产台账的查询、含注销、查看、新增、复制、修改、改编号确认、删除及 Excel 导出；制造厂、安装地点、制造日期、本机编号、保管人、币种和外币原值随卡片保存（`w_zc_zcgl`、`w_zcgl_kp`）。
- 附属设备随整卡事务保存，数量和单价精确计算；列表可逐格修改名称、规格、单位、参考编号、制造厂和本机编号，最多 500 张一批，整批保存失败保留输入并回滚（`w_zcgl_kp_fssb`、`w_zc_zcgl`）。
- 期初卡片及附属设备双工作表导入、预览、入库、导出回导，兼容旧 22 列文件；扩展资料不同的重导拒绝覆盖，坏文件、公式及过期预览不能继续确认（`w_xt_kgzb_zc`）。
- 平均年限法和工作量法的月工作量录入、折旧预览与确认、缺项明确跳过、尾差及累计上限、连续月份和重复计提保护；合法零金额批次无需虚构凭证即可结账（`w_zjjs`）。
- 折旧凭证设置、分录预览、生成、删除、来源跳转与最后月逆序取消；删除及编号重排先展示完整影响，审核和过账来源不能直接删除（`w_pz_build`、`w_zc_qxfz`）。
- 原值调整链、差异复核、逆序撤销和资产注销、清理凭证、撤销注销；以前月份的历史来源保留，受影响月份及关闭期间在事务内复核（`w_zcgl_yztz`、`w_zcgl_delete`）。
- 按日期转移部门、用途、状态、安装地点、保管人及数量，保存完整前后值、原因和操作员；只能逆序撤销，受影响月份已计提时须先取消，历史报表按当时分配取数（`zc_sbbd`、`zc_zcbdb`）。
- 按使用日期重算累计折旧，逐资产展示前后金额、月数及差额；保存时重建期初及已有月份，保留原数快照，多次重算（含零差额）可逆序撤回至原数。卡片版本持续递增，外部修改、其他后续业务、来源凭证及关闭期间阻止覆盖，列表显示可撤回状态或具体原因（`w_zc_zcgl.ue_action_zjjs`）。
- 期初页提供五分钟有效的受保护重置预览，核对账套名称、当前管理员密码及清空文字；待审核来源经共享凭证服务处理，审核来源拒绝清空，整账保护备份、排他替换、失败回滚和重新登录使用共享维护流程（`w_xt_kgzb_zc`）。
- 重置后可重新登录并预览、恢复重置前完整保护副本；校验文件摘要、账套、权限及当前版本，再次核对名称、密码和文字，恢复前也完整备份当前账套；此操作覆盖重置后所有模块的变更。
- 折旧综合查询支持金额、日期、数量、工作量、扩展资料及部门等字段，最多 20 条条件、并且/或者及 12 层括号，自选显示列、最多 5 个排序字段、隐藏连续重复文字和每位操作员 20 个查询定义；错误条件整次拒绝，旧链接及 URL 恢复保留，编辑、加载和失败时禁止沿用旧结果输出（`w_zjgl_cx`）。
- 折旧明细、分布、资产明细账、清单、附属设备、到期及年度增减清单、资产分布、台账的合计、Excel 和打印；全量刷新逐次确认包含全部单据及继续刷新（`w_zjgl`、`w_zjgl_fb`、`w_zcgl_fb`、`w_zcgl_nd`）。
- 独立资产卡片打印，按设备分页的明细账、台账及承前页/过次页余额，A4/B5、颜色、标尺、打印比例和 HTML 文件输出；标签保持 88×51mm，序号范围、颜色、逐张缩放预览、字段及标题设置、严格校验的 JSON 版式导入导出共用打印内容（`w_zcgl_label`、`w_preview_zc_mxz`、`w_print_tz`）。
- 统一置数先预览再确认规格、单位、名称、参考编号、制造厂、本机编号、购置/制造日期、未折旧年限及编号补零，逐项列明锁定和冲突（`w_zcgl_zs`）。
- 卡片、列表、基础档案、转移、调整、注销、工作量、设置、版式及待导入数据接入未保存提醒；非法金额原文保留，保存、快捷保存及离开前保存统一拒绝，修正后才提交。
- 非输入框内 Ctrl+A 新增、Ctrl+K 复制、Ctrl+D 确认删除、Ctrl+F 定位、Ctrl+Q 折旧查询、Ctrl+P 打印，首/上/下/末记录移动；Alt+N 新增、编辑内 Ctrl+S 保存、Shift+F10 重算保留。

## 计算与保护约定

- 本位币金额按整数分保存，数量、工作量和外币原值最多六位小数；外币原值独立保留，不自动换算本位币原值。
- 使用当月不提，次月开始；重算时启用前缺少逐月状态记录的部分使用最早可还原状态，工作量法使用已录的期初累计及逐月工作量，预览明确列出依据。
- 期初 XLSX 只承载卡片及期初累计数，不能代替包含调整、转移、注销、凭证和其他模块的整账备份。

## 未完成及分工

- 其他折旧方法的原版公式尚无可核实资料，未推断实现。
- 不兼容原版 PowerBuilder 专有二进制打印文件；新版提供可导入导出的 JSON 版式和自包含 HTML 输出，未复制原版程序及资源。
- 原版任意坐标拖版及专有单页/双页账册控制未逐项复刻；物理打印机、Windows 桌面和主框架菜单由共享壳及桌面任务继续核对。
