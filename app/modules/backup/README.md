# 备份恢复（M18 / W2）

功能清单（对照 `qingsong/main` 的 `bf.md`、`misc.md`、`menus.md`、`rules.md`）：

- 已实现 · `w_bf`「数据备份」/ 系统管理「数据备份」：全部 core/模块表的 SQLite 在线一致快照；名称必填、同名独立保存、不覆盖已有文件；进度、取消、幂等请求、空间/目录检查、暂存校验后发布。核心表缺失、数据库损坏、报表或打印模块迁移不匹配则拒绝。后台作业持账套租约、复核原操作员权限，关闭与维护等待终态、清理及日志。
- 已实现 · `w_hf`「数据恢复」/ 系统管理「数据恢复」、`w_tzjl_get`「引入备份文件」：自描述可携带包上传/下载；预览账套名、启用/当前期间及备份时间；SHA-256、长度、SQLite 完整性、外键、核心表、迁移与应用版本校验。错误不静默跳过、不自动修补原包。管理员密码及文字确认后恢复成新 UUID 副本，保留原账套，撤销原会话后重新登录；取消、过期、目标冲突拒绝；同计划重试认领只属于本计划的完整副本。
- 本次实现 · `w_hf` / `w_tzjl_get` 新副本保护：拒绝符号链接、硬链接与已有 WAL/SHM/journal 的目标；发布失败清理暂存，保留原财务数据。Windows 无 `O_NOFOLLOW`、文件占用和权限错误用合成故障回归，尚未 Windows 实机验收。
- 已实现 · `w_hf` 覆盖准备：完整 `pre-restore` 保护备份；备份失败、目标变化、确认过期或取消均拒绝；保护备份不能在本页删除。覆盖执行始终阻止，原覆盖 E2E skip 保留。
- 本次实现 · `w_autobak`「系统自动备份设置」：默认开启；目录不能为空且必须真实可写；持久设置启动/退出、定时间隔、保留份数。运行时启动接入已有账套，新建/恢复账套无需页面操作，一分钟内扫描接入；保存配置立即调整定时。系统任务使用 `withSystemBook` 租约、串行不重入，正常退出等待完整校验/轮替/日志；退出备份失败拒绝关闭。状态页显示实际下次安排及失败原因。
- 已实现 · `w_autobak` 保留规则：成功新备份后仅轮替本账套有效自建自动包，保留手动、保护、损坏及未知文件；旧包删除失败保留旧包并记录原因。
- 已实现 · `w_tzjl_get_all`「批量引入备份文件」/ 文件菜单隐藏「模块管理 Ctrl+A」原入口所对应的引入行为：浏览器多包逐项预检，逐项显示坏包/重复来源 ID，独立预览、确认和取消；重复包复用已建副本，不静默覆盖。统一导航提供「备份恢复」入口，未占用全局 Ctrl+A。
- 已实现 · 换机保护：新副本保留业务行 ID、整数分金额、来源引用和操作员凭据，更新账套 UUID；清空源机器受管备份/恢复计划引用，不复制进程会话。表格列宽记忆；查看、创建、校验、导出、恢复、设置、删除权限分别检查。
- 有意不做 · 原版 A: 软盘 1.44 MB 限制、双套本地/数据库备份流程、账套 36 个限制和保留字编码：改为完整 SQLite 包、容量/空间校验及随机 UUID；不恢复旧限制。
- 有意不做（本模块）· `w_bf_98001`「审计导出」、`w_bf_98001_bak`「审计接口」、`w_bf_2010_xzsy`「单位基本信息」及年度/目录/报表格式规则归 M17；`w_ini_bf`「仅初始化部分数据」不冒充完整备份；`w_bakupdata`/`w_bakupdata_bak` 切换入口归账套/壳，完整备份路径已覆盖同类目录、缺文件和容量拦截。原软件注册、加密狗、云报表/移动端按项目要求不做。

未完成：原账套覆盖恢复及原定覆盖 E2E；共享 `maintainBook` 当前仅支持 reconnect，缺由唯一 owner 提供的原子 swap/失败回滚及 Windows 外部连接/锁协议，模块不调用 close/pathOf 绕锁。共享层受管流式传输仍缺，浏览器单包最多 32 MiB、本机单包阶段上限 1 GiB；批量任务跨页面持续执行；原版 SQL Anywhere `.bak` 导入；原版按每 N 天/每月第 N 天的日历调度（当前仅固定分钟间隔）；原版任意磁盘目录选择（当前受管目录）；异常断电/强杀无法执行退出备份；Windows 原生实机回归。摘要校验不证明来源可信，含操作员资料的备份应在授权本地保存。
