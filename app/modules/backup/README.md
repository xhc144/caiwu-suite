# 备份恢复（M18）

- `w_bf`：当前 `.caiwu` 的 SQLite 在线完整快照，包含 core 与所有模块表；后台进度、取消、请求幂等、同名独立保存。暂存后真实校验并原子发布。后台作业独立持有账套租约，保留原操作员并复核创建权限；维护、缓存关闭和正常退出等待最终状态、日志与清理结束，最终写入失败时拒绝关闭。
- `w_hf`、`w_tzjl_get`：自描述可携带包上传/下载、只读预览、SHA-256/长度/SQLite 完整性/核心表/迁移及应用版本校验；管理员密码与文字确认后恢复成新 UUID 副本，原账套保留，旧会话失效后重新登录。目标新 ID 已有数据库辅助文件或硬链接时拒绝发布或认领。
- `w_hf` 覆盖准备：完整 `pre-restore` 保护备份与目标变化、确认过期/取消检查；覆盖执行始终阻止。
- `w_autobak`：默认开启的持久配置、受管目录写入检查、可接入的启动/定时/退出控制器、串行不重入及退出等待；成功新备份后只轮替本账套自建有效自动备份，保留手动、保护和未知文件。
- `w_tzjl_get_all`：浏览器多包逐项预检、重复来源 ID 提示、独立确认和取消；重新上传同一包复用已建副本，不静默覆盖。
- 表格列宽可调并记忆；权限分别控制查看、创建、校验、导出、恢复、设置与删除。摘要校验不证明来源可信。备份包含操作员资料，应在授权本地保存。

未完成：原账套覆盖恢复及原定覆盖 E2E（本模块尚未接入共享层的原子恢复接口）；启动时账套发现扫描转后台的优化尚未接回；共享层受管流式传输（浏览器单包最多 32 MiB，本机单包阶段上限 1 GiB）；批量任务跨页面持续执行。原版 SQL Anywhere `.bak`、审计导出（M17）及仅初始化部分数据的 `w_ini_bf` 不作完整备份导入。新副本保留业务行 ID 和操作员凭据，账套 ID 更新；清空源机器受管备份/恢复计划引用，不复制进程会话。

自动备份由服务宿主统一调度，本模块不另建自动备份控制器。
