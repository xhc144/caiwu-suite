# 备份恢复（M18）

- `w_bf`：完整保存账套及所有业务、报表和打印设置；支持后台进度、取消、重复请求复用、同名独立保存，校验通过后才发布备份包。
- `w_hf`：恢复前展示来源账套、单位、制度、启用和当前期间、备份时间及恢复目标。可恢复为新账套，也可覆盖当前账套；覆盖前先生成完整保护备份，核对管理员密码和指定文字。准备后目标有变化、确认过期或取消均拒绝执行。
- `w_hf` 覆盖恢复：使用统一维护服务排空请求、复核权限和目标、保留保护副本，再替换并检查账套；失败回滚，完成后重新登录。目标编号和名称保留，业务数据与操作员资料恢复到备份状态；本机已有有效备份（含来源包和历史保护）经校验后保留，仍可下载、校验及恢复。取消准备时清理临时恢复文件，过期及退出清理由本地服务处理。
- `w_tzjl_get`：备份包可携带到另一台电脑，上传校验后恢复为独立新账套；不复制源机器的受管文件登记、恢复计划和会话。新副本保留业务行编号、来源锁与操作员权限，原账套保留。
- `w_hf`、`w_tzjl_get`：同模块的已知历史版本备份先核对迁移记录和结构，再在隔离副本升级后恢复；原包保持不变。未知、断档、内容不符或来自更新版本的备份仍拒绝。
- `w_tzjl_get_all`：多包逐项预检、重复来源提醒、逐项确认和取消；重新上传同一包可复用已建副本，不静默覆盖。
- `w_autobak`：默认启用，设置启动、定时和正常退出备份，由本地服务统一调度。只轮替本账套有效自动备份，保留手动、恢复前保护及未知文件；页面显示配置、历史成功和失败原因。
- 查看、创建、校验、下载、恢复、设置与删除分别授权。长度、摘要、SQLite完整性、迁移和程序版本校验不能证明来源可信，须选择授权来源的备份。

未完成：浏览器上传下载单包上限32 MiB、本机备份上限1 GiB；更大包需要统一流式传输接口。批量任务尚不跨页面持续执行；自动备份下次准确时刻尚需宿主提供实时状态。原版SQL Anywhere `.bak`、审计导出及部分初始化备份不作为新版完整备份导入。

功能对照依据：`docs/original-analysis/products/qingsong/main/menus.md`、`rules.md` 的 `w_bf`、`w_hf`、`w_autobak`、`w_tzjl_get`、`w_tzjl_get_all`，以及 `windows/bf.md`、`windows/misc.md`、`windows/tzjl.md`。
