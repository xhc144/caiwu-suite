# 成本核算

- `w_cb_hz`（日常业务→成本核算）：真实库存月末加权试算，按仓库/产品逐月结转；整分累计分配尾差、实盘盈亏、零数量金额调整；保存/取消本模块试算、来源版本复核。**试算不是正式核算，不锁库存。**
- `w_cb_fgz`（系统管理→取消成本核算）：初始期间保护及缺共享接口阻断；正式批次撤销未实现。
- `w_cb_pz`、`w_ck_rk1`、`w_ck_ck1`（日常业务→凭证生成）：入库（存货+进项税/付款）、销售收入（收款/收入+销项税）、已正式核算出库成本（成本/存货）的分录预览；明细科目、价税平衡、来源用途、辅助项、数量科目和期间检查。无写凭证按钮。
- `w_cb_hzsj_cblr`、`w_ck_xsmxz/w_ck_xsmxz1`（成本利润表/销售明细账）：按日期、仓库、产品范围查询销售出库，不含税收入、税额、已核算成本、销售毛利及来源穿透；当月仅在全局/头行批次一致且全局/头截止均为月末时使用正式成本。历史月份尚无共享快照证明批次链，明确显示“历史成本未知”；未知值留空且不合计毛利，保存试算不会冒充正式成本。
- `w_cb_pdk/w_cb_pdk_1`：读取真实盘点表的实盘数量，过期账面数量阻止试算；盘点维护仍归仓库模块。

未完成：正式成本提交及全月来源锁、仅最后批次的正式取消核算、库存期初/单据/盘点核算字段回写、凭证真实生成/删除/重生成与审核过账保护联动、同单收入与成本双凭证关联、盘点凭证、生产成本完工入库与材料/人工/制造费用分摊、销售费用/附加税与净利润、凭证类型/年月/手工编号与批量范围设置、Excel/打印和全功能原版利润表。主实现没有 FIFO：原 `w_cb_hz` 明确规定加权平均法。正式核算/凭证写入因 core 没有库存事务契约而阻断，不能凭本模块独立修改 inventory 表。
