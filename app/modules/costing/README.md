# 成本核算

- `w_cb_hz`（日常业务→成本核算）：按单月、仓库/产品进行月末加权试算；明确确认后通过 core 库存桥在同一事务保存正式成本批次、出库成本、盘点/零数量调整和月末结存，锁定本月来源。没有库存数据的月份可明确确认发布真实空月批次，连续承接至首个业务月，不补造期初或结存。拒绝旧预览、跳月、缺失正式期初及断链历史；保存/取消试算仍独立保留，不能替代正式发布。
- `w_cb_fgz`（系统管理→取消成本核算）：在成本核算页查看正式记录，仅最后有效月份可确认撤销；成本记录、库存前态和操作日志同事务处理，关联凭证已审核/过账时拒绝。未审核成本凭证由共享桥释放并删除一次，入库/收入用途保留；初始开账日期提示与版本保护保留。
- `w_cb_pz`、`w_ck_rk1`、`w_ck_ck1`（日常业务→凭证生成）：入库（存货+进项税/付款）、销售收入（收款/收入+销项税）、正式出库成本（成本/存货）的分录预览；明细科目、价税平衡、来源用途、辅助项、数量科目和期间检查。无写凭证按钮。
- `w_cb_hzsj_cblr`、`w_ck_xsmxz/w_ck_xsmxz1`（成本利润表/销售明细账）：按日期、仓库、产品范围查询不含税销售收入、税额、正式销售成本、毛利及来源穿透。历史和当月成本均要求控制锚点至启用月的完整有效批次链，以及头行批次/期间/月末截止一致；证据不足时成本和毛利留空，不汇总未知毛利。
- `w_cb_pdk/w_cb_pdk_1`：从共享快照读取实盘数量，盘点账面数量过期时阻止核算；盘点维护仍归仓库模块。所有库存读取和写入统一走 `svc.inventory`，不访问库存私有表。
