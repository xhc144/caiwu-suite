# 成本核算

- `w_cb_hz`：按仓库、产品逐月进行月末加权平均试算和正式核算，累计分配整分尾差，按实盘数量计算盘盈亏，单列零数量金额调整；空月份也可连续核算，正式提交复核来源版本并锁定当月单据、盘点及期初。
- `w_cb_fgz`：预览后仅取消最后一个正式月份，恢复核算字段与上期结存；删除该月未审核成本凭证，保留入库和收入凭证。删除前展示完整编号影响，关联凭证已审核或过账时阻止取消。
- `w_cb_pz`、`w_ck_rk1`、`w_ck_ck1`：实际生成入库、销售收入、出库成本凭证，支持凭证类型和账套手工编号；删除、重新生成与来源关联在同一事务中完成，失败全部回滚。同一销售单的收入、成本凭证独立保存并可互相查阅。
- 发票转出的销售出库单仅在本功能生成成本凭证；收入凭证由发票功能管理，收入制证列表和服务端写入均排除该来源，避免同一业务重复确认收入。
- `w_cb_pdk/w_cb_pdk_1`：读取仓库维护的实盘表，过期账面数量阻止核算；正式核算后可生成盘盈亏凭证。取消该月核算前须先删除盘点凭证，审核或过账后的盘点凭证不能删除。
- `w_cb_hzsj_cblr`、`w_ck_xsmxz/w_ck_xsmxz1`：收入成本利润表按仓库、产品汇总，销售明细账逐单逐行查询；两表均可导出 Excel、打印 A4，包含单位名称、日期和金额单位。销售毛利按不含税收入减销售成本计算，未核算或历史批次无法核验时相关金额留空。
- 正式核算、取消、保存试算及凭证写入均执行服务端期间和权限检查；重复核算请求不重复入账，来源变化后须重新预览。历史成本由从启用月连续承接至最新月份的正式批次链核验。

规则来源：`docs/original-analysis/products/chengben/main/menus.md`、`windows/cb.md`、`windows/ck.md` 和 `rules.md` 中上述窗口。盘点默认借贷对应产品存货科目与用户选定的待处理财产损溢明细科目，不自动推定损失责任或后续损益处理。

未完成：生产成本完工入库及材料、人工、制造费用分摊；销售费用、附加税分摊与净利润；来源缺少外币金额时的外币科目凭证；按日期范围一次生成多张凭证。零成本且仅有一条有效数量分录的凭证受共享凭证校验限制，库存数量和成本核算照常保存，不能伪造零金额平衡行；需要共享层支持单行数量凭证后接回。盘点凭证与取消核算的一步合并删除尚需共享库存接口扩展，当前支持先删除盘点凭证再取消的完整逆向流程。
