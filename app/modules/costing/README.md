# 成本核算

- `w_cb_hz`：按仓库、产品逐月进行月末加权平均试算和正式核算，整分尾差累计分配；按实盘数量计算盘盈亏，单列零数量金额调整，空月份也可连续核算。正式保存复核来源版本，并锁定当月单据、盘点及期初。
- `w_cb_fgz`：预览后仅取消最后一个正式月份，恢复核算字段与上期结存，删除未审核成本凭证并保留入库、收入凭证；删除前展示完整编号影响，关联凭证已审核或过账时阻止取消。
- `w_cb_pz`、`w_ck_rk1`、`w_ck_ck1`：实际生成、删除及重新生成入库、销售收入和出库成本凭证，支持凭证类型及手工编号，失败全部回滚；同一销售单的收入和成本凭证可以分别查阅，零金额的有效数量分录也能保存。
- 发票转出的销售出库单仅在此生成成本凭证；收入候选、单张写入和日期批量处理均排除发票来源，防止重复确认收入。
- `w_cb_pz.wf_wgrk`、`zx_cbfpb`：从材料、人工、制造费用三个成本明细科目归集余额，包含未过账正式凭证；本版按完工数量乘产品系数分别分摊三类费用，整分金额严格守恒，接近零的系数按原版恢复为 1。预览后同时保存完工入库单、成本分摊明细及凭证；草稿能保存未完成输入，重开后继续，未审核且未核算时可预览编号影响后一并取消。
- 来源原币资料可保存币种、汇率、净额、税额及价税合计，并校验每行折算与尾差；原币按整分分配到入库及收入分录。来源金额修改后必须重新核对，正式核算和取消核算不会误使原币资料失效。
- `w_cb_pz` 日期范围处理可一次预览多张单据及完整分录，逐张生成或重新生成；跨月保留来源月份，成功项才使用手工编号。失败和跳过逐单列出原因，已审核、过账及已有凭证不会被普通批量覆盖，修正后可以重新预览处理。
- `w_cb_pdk/w_cb_pdk_1`：读取仓库维护的实盘表，过期账面数量阻止核算；正式核算后可生成盘盈亏凭证，取消该月核算前先删除盘点凭证，审核或过账后的凭证不能删除。
- `w_cb_hzsj_cblr`、`w_ck_xsmxz/w_ck_xsmxz1`：收入成本利润表按仓库、产品汇总，销售明细账逐单逐行查询；两表可导出 Excel、打印 A4，包含单位名称、日期和金额单位。正式批次链不能核验的成本留空，不以试算冒充正式成本。
- 销售费用及附加税按完整月份的不含税销售收入分摊，收入全为零时按数量分摊，再应用日期、仓库、产品查询范围；销售净利为毛利减销售费用及附加税，销项税不重复扣减。未设置归集或成本未知时相应金额留空。
- 净利润结转预览本账套所有应转本年利润的损益余额，保留辅助项、外币及数量；明确指定转留存收益等用途的科目不混入本年利润。生成和取消均使用正式凭证及编号预览，已审核或过账时保护原凭证。

规则来源：`docs/original-analysis/products/chengben/main/menus.md`、`windows/cb.md`、`windows/ck.md`、`rules.md` 和 `data/tables.md`。静态资料未包含生产分摊的完整计算公式，上述数量乘系数是本版明确采用的分摊口径。盘点先对应产品存货科目与选定的待处理财产损溢明细，不自动推定损失责任或后续损益处理。

使用限制：现有库存单据仅支持六位小数单价，分摊金额无法准确表示时整笔拒绝，避免入库金额漂移；需共享库存接口提供直接金额输入后扩大可保存范围。采购、销售原币不能冒充正式出库成本或盘点的原币，这两类来源未提供原币时拒绝外币科目。盘点凭证与取消核算的一步删除尚需共享库存接口扩展，当前先删除盘点凭证、再取消核算的逆向流程可用。
