# 小企业三表

依据 `rules/sources/official/small-appendix.pdf` 第68—82页、《小企业会计准则》及 `rules/sources.json` 的税金及附加更名登记。保留53/32/22项行次；历史税费项目仅承接真实账簿发生，不用于计算现行税费。

- `w_bb_main/get`：制度描述器、标准母科目动态匹配、非标准科目中文项目映射；配置包含账套、版本、依据和报告时点，通过报表模块参数持久保存。
- `w_bb_proc`：资产负债表期末/年初，往来逐末级及辅助对象分向，期限分析，有符号存货组成，折旧摊销，实收资本及已归还投资，未结转损益与费用化研发跨表闭合。
- 利润表本年累计/本月，年报本年/上年全年；科目明细与逐笔拆分保留退款及净额，只排真实损益结转。费用化研发按范围首尾未转损益余额调整，实际转入管理费用后抵销。
- 现金流量表逐账户日期确认可支付范围，逐现金分录拆分守恒，退款冲减、内部划转抵销、非现金排除及首尾现金核对。
- 年中启用按真实期初明细及累计还原年初；启用前损益结转及现金分类分别确认、核对累计。不完整来源会给出修正入口；首年无比较与比较资料缺失分开表达。
- `w_bb_saveas`：真实数值xlsx，合并标题、列宽、金额格式、打印区域和重复表头；A4分页打印任务，单位、报告日期、金额单位和首尾项目来自同一结果。

公共挂接入口在 `statutory.server.ts`：配置读取/保存、配置页真实来源、同事务准备、成功输出审核、来源复核。`statutory.web.tsx` 提供配置、结果及导出打印组件；`output.ts` 仅序列化公共入口批准的成功快照。

未完成：当前main尚无本制度的公共注册、安装、原子成功快照和输出路由。须由唯一公共接线任务挂接上述入口，并在真实报表管理页完成新增、配置、生成、刷新、下载、打印、失败保留旧成功快照与幂等验收。当前本域组件测试及core测试不替代这项系统入口验收。
