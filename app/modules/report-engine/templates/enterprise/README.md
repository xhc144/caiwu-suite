# 企业财务报表

依据财会〔2019〕6号附件2第1—18页，适用于已执行新金融、新收入和新租赁准则的一般企业。四张基本报表不能替代附注。科目仅匹配实际账套名称和上级语义，不编造正式科目编码。

- `w_bb_get/main/proc`：四表描述、严格配置、两日期分类、完整期间、损益结转、税后其他综合收益、加权股份及年度权益矩阵。
- `w_bb_def_help/def/bbsetup`：中文科目匹配、合同与期限分项、金融工具、现金范围、逐笔现金和权益事件配置。
- `w_bb_saveas`：同一结果输出数值xlsx和分页A4；权益矩阵按年度与权益列分组，重复项目和表头。
- 其他应收、应付及利息股利按明细借贷方向和报告日流动性列报；备抵绑定对应明细，金融工具权益事件按同科目、同辅助对象的期末分类取数。
- 现金限制及解除依证监会《监管规则适用指引——会计类第1号》1-25二，核实原现金资格、变动金额及实际用途，分项计入三类活动；缺分类依据拒绝生成。纯政策追溯重列各期范围与逐笔分类，不作为期中现金收付或汇兑调节。
- 财会〔2026〕11号按主体类别于2027／2029／2030年执行，显式提前执行另存采用日期；不因发布日期切换历史格式。2026科目征求稿不作编码依据。
- 解释19的补偿性资产按实际流动性列其他流动／非流动资产；解释20的金融分类保留本金加利息特征与业务模式依据，报告消费已入账金额，不替代确认计量和外币折算。

四表已接入本账套报表管理，可保存配置、确认来源、生成并保留成功结果、导出Excel和打印。来源变更后需重新确认。
