# 民非2026法定三表

依据 `rules/sources/official/nonprofit-2026.pdf` 第28—36、47—49、127—153页及 `transition-2025-6.pdf` 第4—5页。

- `w_bb_main/get`：按实际账套制度与适用日期提供三表目录；标准一级科目自动对应，新增科目可配置。
- `w_bb_proc`：完整资产负债表年初与期末、业务活动表六栏与双向互转/以前年度调整、年度现金流量及比较；逐笔资源与现金拆分、两时点到期和备抵、往来对象分向、受托现金移列、结转核对及表间勾稽。
- 中文配置组件录入资源原始条款、取得/使用关联、余额分析、实际净资产事件、现金范围与逐笔分配（同一科目可拆普通、受限及受托部分）；确认不由末级科目映射自动产生。
- 2026业务活动和现金流量比较栏明确“不要求填列”；401仍使用新账真实年初。2027起读取真实上年来源，明细重列后重算合计并复核承接。
- `w_bb_saveas`：同一已核验快照生成真实xlsx、A4打印HTML，活动表横向、分页重复表头。
- 民非原 `w_bb_proc` 有更多参数、辅助类型/内容、99期间和辅助占位，与其他产品窗口有差异；原公式校验和通用编辑器继续由公共引擎负责。

接线接口：`nonprofitDescriptor`（`statutory.server.ts`）包含目录、配置/报告期校验、核心服务取数、生成、绑定复核和勾稽；`NonprofitConfigurationPanel`（`statutory.web.tsx`）接收保存/生成回调。生成须在公共现有事务内读取已保存配置，成功后保存 `statement` 与 `binding`；幂等回放、导出和打印须再次 `verify`，失败不得写新快照。复制、改编号、导入须保留制度标识和原绑定。`statementSnapshot`、`nonprofitWorkbookBase64`、`nonprofitPrintHtml`只消费同一有效快照。这些入口尚未被main自动发现。

未完成：公共目录/安装、配置持久保存与原子生成/输出接线及真实HTTP全流程验收；年中启用前逐笔来源导入与累计承接；中期及混合资金期初的政策追溯逐期/逐部分来源承接（年度普通现金和净资产总额追溯已实现，底稿须借贷平衡并由次年真实年初逐明细承接）。缺年度年初/连续期间的账套明确要求补充来源，不默认为零。原版99期间、通用S/W/F别名、旧二进制引入及完整编辑器由公共任务负责。
