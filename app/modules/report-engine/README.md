菜单补漏（含历史/默认隐藏项）：

- `m_bb_def` / `m_bb_def_bak` 文件：已实现打开选择、Ctrl+S、生成/现场重算、返回、模板导出（列表）、打印（结果）；未实现 Ctrl+O/Ctrl+P、定义页另存、独立打印预览、设置/清除打印标题、打印页/打印机设置。
- 编辑：已实现输入框原生复制粘贴、清空当前格按钮；本次实现区域粘贴及撤销/重做按钮（Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z 限非输入框）。未实现区域 Ctrl+C/Ctrl+V/剪切、Del 全格清除、插行 Ctrl+I/删行 Ctrl+K、插删列、画线、设置/取消分页线。
- 显示：已实现尺寸编辑、定义/结果页面；未实现独立增减行列、网格显隐、原地定义/显示、公式显隐、sheet显隐 Alt+S。
- 格式/帮助：已实现上述基础行高/列宽/排列/数字格式和 F8；本次增加指南；未实现完整边框/字体/乱码处理、报税 Ctrl+F2、汇总余额表快捷入口、窗口层叠/平铺。
- `m_bb_def_gs` 全部编辑/文件/帮助/格式/显示/窗口项和 `m_bb_htpj` 另存/页设/设置/预览/打印/选打/退出均保留给打印 owner；普通报表不能替代。
- `m_bb_saveas` / `m_bb_saveas_get`：已实现本报表另存 xlsx/JSON；未实现复用数据表读入、区域复制粘贴、原窗口退出工作流，不能以报表粘贴替代业务导入。

规则补漏：已有编码/尺寸/空名/重复/缺源、只读、过期覆盖、公式括号/未知函数/缺运算符/除零、未过账和删除确认；本次补向导/审核语法反馈、粘贴整批拒绝。仍未实现主分账低编号、原文件存在/兼容、文件替换确认、打印标题清除、指定税表/已生成/申报格式限制、旧数据转入日期/覆盖/编码层级/逐行统计。孤立提示“11”缺业务语义，待核。现有 JSON 校验不等于原格式兼容。

其余保留缺项：外币/数量本年累计、现金流量期初项目分配（core 无可靠口径）；任意布尔审核式；完整辅助项穿透/逐取数追踪；浏览器前后退及所有壳关闭路径确认、不同 revision 本机草稿合并；超过5000已定义格和超大报表性能；完整旧报表行为；三套法定报表、报税、Windows 实机打印/桌面验收。现有网格30行×20列窗口，最多5000格；公式2000字符/512项/40层语法/64层引用/每次生成100000步。粘贴每次500格/1MB/每格2000字，遇合并格先拆分，不自动平移公式引用；撤销历史只在当前页面有效，保存后重置。

共享需求：内置三表须有报表目录（稳定标识/版本/制度及产品适配/来源/包含报表/安装状态）和显式安装合同（目标编码/冲突处理/权限/revision及幂等键/同事务全成或全不成）。这是待共享 owner 确认的需求，未新增科目模板注册接口；现有单张 `importTemplate` 不能冒充内置安装。另需统一导航/关闭守卫、缺失 core 口径、原函数数据和扩展样式合同。本任务未改共享层、服务端、公式引擎、模板或三套法定报表目录。
