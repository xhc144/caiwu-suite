# 报表引擎

- `w_bb_main/add/copy/main_bhxg`：本账套列表、新增、复制、改编号、确认删除；只读模板可复制，定义带乐观锁。
- `w_bb_def/bbsetup/def_colw/def_rowh/def_format`：可键盘编辑的单元格网格、文本/数值/金额/公式、尺寸、行高列宽、对齐/换行/粗体/数字格式、合并拆分、未保存确认和本机草稿。
- `w_bb_def_help/help`：F8 向导；白名单 `BALANCE(科目,指标,单位,币种,方向,辅助类型,辅助编码)`、`SUM(区域或计算项)`、`REF(报表编码,单元格)`；支持四则运算及一元负号。参数为字符串，金额以分计算并四舍五入落分，显示元；数量/比例保留10位小数。
- `w_bb_proc`：工厂的新profile以`mode:declaration`显式确认映射，服务端持久化并导出为`mode:bound`及原账套/来源印记；旧绑定文件换编码重导入也不能洗白变化的来源。持久profile切片在同一生成事务复核已保存定义/revision、实际依赖、范围、来源与科目指纹，失败零新快照；幂等回放同样复核。已建立期间生成/重算、未过账数量确认、明确口径、真实总账取数、同事务表间依赖、勾稽差额/阈值/错误、保留上次成功快照。
- `w_bb_get/saveas`：严格 `ReportTemplateSchema` JSON 导入/导出，`templates/example.json` 非法定示例；公式在 `cells[].kind/source` 定义。`exportResult`强制拒绝审核fail/error、profile或相关来源失配；旧结果保留供查看。无profile输出明确标为非正式自定义试算，绑定结果也只标为局部切片，不宣称完整法定报表。结果导出真实 xlsx（含合并/基本格式，原公式仅为注释数据），调用 `printHtml` 打印。

未完成：原版 dba.bbfun 数据行缺失，S/W/F 基本函数旧别名未兼容；外币/数量本年累计、现金流量期初分配；跨账套复制及原版二进制/备份引入；批量粘贴、撤销重做、插删行列、字体/边框/分页与完整套打；任意布尔审核表达式（目前为左右差额）；辅助项穿透参数与逐取数调用追踪；浏览器前进/后退及所有壳关闭路径统一确认、不同版本本机草稿的合并恢复；5000个已定义单元格以上和超大报表性能优化。公式限制2000字符/512项/40层语法嵌套/64层引用/一次生成100000步，网格按30行×20列窗口查看。企业采购两行、小企业301存货、民非401/402/403仅提供各自README列明的局部取数与门禁；完整三套法定报表、报税上传和共享打印/桌面仍未完成。
