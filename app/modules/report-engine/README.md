# 报表引擎

- `w_bb_main/add/copy/main_bhxg`：本账套新增、复制、改编号、确认删除；只读模板可复制，保存时检查版本，防止覆盖他人修改。
- `w_bb_def/bbsetup/def_colw/def_rowh/def_format`：键盘逐格编辑文本、数值、金额和公式；插删行列会同步移动内容、格式、合并区、审核公式、行高列宽和分页设置。
- `w_bb_def` 编辑菜单：最多100步撤销重做；矩形区域批量粘贴，支持 Excel 制表符、引号和字段内换行，空字段清空对应格。金额按元输入并四舍五入到分，非法内容、越界或合并冲突时整批保留原值。
- `w_bb_def` 格式菜单：按单格或指定区域设置字体、字号、颜色、粗斜体、下划线、四边边框、对齐、换行、数字格式及合并拆分。
- `w_bb_def_help/help`：F8 向导；支持 `BALANCE(科目,指标,单位,币种,方向,辅助类型,辅助编码)`、`SUM(区域或计算项)`、`REF(报表编码,单元格)` 及四则运算、一元负号。保存插删时，同事务调整其他自定义报表的引用；仍被引用的单元格不能删除，只读引用不能自动修改。
- `w_bb_def_help/help`：外币和数量支持完整年度的借、贷累计；年中启用且缺少启用前独立来源时明确提示，不能按零出表。
- `w_bb_def` 审核公式：可比较左右差额，或使用比较符、AND、OR、NOT 和括号组合条件；金额、数量和币种保持一致，计算错误单独提示。插删行列及被引用报表移动时同步更新条件。
- `w_bb_proc`：已建立期间生成/重算、未过账确认、明确取数口径、真实总账取数、表间依赖与勾稽差额检查；失败保留上次成功结果。
- `w_bb_def_gs` 打印菜单：A4/A5/B5、横纵方向、页边距、行前分页、重复表头和自动分页，跨行合并保持完整；套打保持原尺寸并设置毫米偏移，仅打印数值和计算结果，超出纸张时明确提示。
- `w_bb_get/saveas`：严格 JSON 定义导入导出；结果导出真实 Excel，保留合并、字体、四边框和打印设置，公式只作为注释。Excel 保留完整内容，预印纸套打使用页面打印入口。
- 编辑器接入统一关闭、关闭全部、同标签离开、切账和桌面退出保存确认；普通标签切换保留草稿。编辑失败保留页面内容和本机草稿；同版本草稿可在刷新后恢复，包括插删步骤。保存期间锁定编辑入口，保存后仍可撤销重做。
- 生成结果逐项列出取数公式的报表、单元格、期间、币种、辅助条件和数值，可按同样条件穿透账簿；Excel 同时保留取数来源。
- 企业法定报表导出按当前选中的报表输出；换期保留完整未保存草稿，来源按所选报告日重新读取。完整草稿使用请求体读取，保存时再次重建来源；编辑和保存保留全部月份配置，仅在校验、核实和生成时投影目标期，仍校验已经失效的来源。

原版功能依据：`docs/original-analysis/products/qingsong/main/menus.md` 的 `m_bb_def/m_bb_def_gs`，以及同目录 `windows/bb.md` 的对应窗口。
