# 账簿

- 总分类账（`w_zc_zc/_1`）：按科目范围逐月查看发生额、本年累计和期末余额，可展开月份并追溯明细；父子不重计，不混加不同计量单位的数量。
- 三栏明细账（`w_zc_slz/_1`）：查看期初、逐笔余额、月小计、本年累计和期末，按期间、科目、辅助对象和币种筛选，凭证只读穿透。
- 现金、银行日记账（`w_zc_xjrjz/w_zc_yhrjz`）：按现金或银行科目标志成账，支持本币、复币和数量格式、日小计、月小计及辅助对象展开。
- 多栏账及辅助多栏账（`w_zc_dlz/w_zc_fhdlz`）：上级科目按直属下级自动分栏，或保存自定义借方、贷方、借减贷栏目；未覆盖科目列入其他栏，辅助对象及未指定对象分别成账，拒绝末级科目与重复计算。
- 辅助明细账（`w_zc_fhslz`）：按客户、部门、人员、项目等对象分别承接期初与逐笔余额，支持三栏、数量、复币和数量复币格式。
- 数量、复币、数量复币账（`w_zc_slz_sl/_fb/_slfb`）：原币按选定外币独立累计，数量保留六位小数，零本币分录与红字保留原借贷侧；未提供的历史累计留空说明。缺省结余单价按本币金额除以数量并四舍五入至六位小数。
- 增值税明细账（`w_zc_zzs/w_xt_tz_zc_zzsmxz`）：自行设置最多五借栏、五贷栏与对应科目；合计按科目并集计算，反向发生列入未分类栏，不自动猜测税务分类。
- 批量转出（`w_zc_saveas`）：选择科目完整导出账页，保留全部明细、小计和累计；Excel金额保存为两位小数文本，数量及单价保持精确文本；多栏超过248栏时阻止另存。
- 连续打印与套打（`w_print_1/w_print_2_zw`）：科目与辅助对象独立换页，可选择有发生或有期初累计的账页、页码范围、连续页号、纸张、边距、偏移及行高；宽表打印正附页，承前与过次页只累计真实发生，不重复加小计。
- 显示列按账套保存并可确认恢复，栏目和映射使用版本检查；保存失败或后台刷新保留编辑草稿。筛选保留在地址中，可明确显示无发生科目。
- 默认仅计已过账，可包含待审核和已审核，始终排除草稿与作废；查询、导出和打印执行服务端权限和期间检查，超量或金额越界明确拒绝。

未验证：真实Windows打印机、实体预印账页的位置与驱动缩放，需要按实际纸张校准。
