# 会计制度科目模板

功能：为系统管理→套账管理/系统初始化中 `w_xt_kgzb_a2`「行业选择」、`w_xt_kgzb_1`「信息确认」、`w_xt_kgzb_3`「一键初始」的**新建账套生成科目**提供数据。五套模板由服务端自动注册，正式模式可列出，复用 core 建账事务；无业务菜单、写接口或独立建账流程。科目级次是账套参数，民非默认 4-2-2，其余默认 3-2-2。

后四套在固定基线的 `rules/sources/official/` 无原文；本次在线核读上述官方完整附件，只保留链接与科目定位，不提交PDF副本。各科目 `source` 标明文件、PDF物理页及名称。双重性质、净损益和结转科目的 `direction` 是应用默认显示方向，不限制实际借贷余额。

测试：独立原文期望表逐项核对、真实SQLite建账和事务失败清理、HTTP逐制度建账/登录/科目读取/隔离/未登录拒绝，以及现有账套选择与登录壳切换。测试使用临时数据目录，不依赖M01。
