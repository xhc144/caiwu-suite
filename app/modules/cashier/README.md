# 出纳

- `w_cn_xtcsh`、`w_cn_lr_qc/_nf`：保存启用期间，本位币现金/银行账户与独立出纳期初；账务期初只读核对，已使用账户初值锁定，停用保留历史。
- `w_cn_lr/_add`、`w_cn_ll/cx`：收付单录入、修改、单笔强确认删除；自动单号、请求幂等、版本检查、必要辅助核算、筛选排序与 Excel 导出。
- `w_cn_pz`：逐单或同月汇总凭证预览、事务生成、批次来源联查与整体撤销；生成后锁定原单，审核/过账后拒撤销。
- `w_cn_lr_get1`、`w_cn_dz`：同库已过账财务分录只读引用、手动多对多等额勾账、确认取消、截止日余额调节表与打印。
- `w_cn_slz/_1`：按账户本位币日记账、期初收付期末、Excel 导出和打印。
