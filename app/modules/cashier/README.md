# 出纳

规则来源：`docs/original-analysis/products/qingsong/cn/{menus,rules,windows/cn,windows/misc}.md`，原表 `cn_mx`、`cn_hz`。以下金额输入和导出均以元显示。

## 功能

- `w_cn_xtcsh`：首次启用保留现有数据；重新初始化先展示账户、期初、收付单、删除历史、支票、勾账与结账范围，核对账套名并输入确认文字。管理员与期间在服务端复核；保护备份完整校验成功后才在事务中清空，失败全部保留。仍有关联凭证时须先按正常流程撤销，不能清空来源后留下凭证。
- `w_cn_lr_qc`、`w_cn_lr_qc_nf`：现金银行末级科目对应本位币或外币账户，保存本位币与原币期初，并只读核对账务期初。使用后锁定关联科目、币种和期初；停用保留历史。
- `w_cn_lr`、`w_cn_lr_add`：收款、付款、辅助项目、票号和备注；单号唯一，重复提交不重复保存，版本冲突有提示。外币须填原币金额及汇率，本位币按四舍五入核对，生成凭证保留原币、汇率和方向。
- `w_cn_ll`、`w_cn_cx`：按日期、账户、摘要、金额、客供、生成及勾账状态筛选、排序和导出 Excel。
- `w_cn_lr_del`：已选单据或当前条件中的日期范围预览，两次输入确认后批量删除；逐笔复核版本、期间、来源及勾账，跳过原因可导出。预览后新增的单据不会混入删除范围，异常保存全部回滚。
- `w_bb_def_cn0_bak`、`w_bb_saveas`：导入 `.xlsx`、UTF-8/GB18030 的 CSV、制表符文本；自动识别常用列，支持手动格式映射与按账套记忆、默认账户及辅助项。日期、账户、币种、金额、原币折算逐行预览；有一行错误就不保存，全部校验通过后整批保存，重复提交不重复导入。
- `w_cn_lr_get1`：同库已过账、未作废账务分录只读引用，出纳不能改删。
- `w_cn_pz`：按单或同月汇总预览及生成凭证，支持本位币、同币种外币对方科目和辅助项目；内部资金划转保留现金流量方向。按账套自动或手工编号，手工连续号先预览并复核占号；来源联查、重复生成保护和整批撤销。撤销先列出全部凭证及删除后编号影响，确认后按共享策略原子删除和重排；审核、过账、勾账后拒绝撤销。
- `w_cn_dz` 及选择、年月、截止日期窗口：同账户同币种对账、手动多对多勾账、按日期的自动等额建议、重复金额人工消歧、快照与唯一占用复核、强确认取消勾账。本位币及原币分别等额才可勾账，两种余额调节表均可导出打印。
- 自动勾账建议全部可翻页，每页 50 项，一次最多确认 200 对；只预选双方唯一的前 200 对，明确其余待分批处理。
- `w_cn_slz`、`w_cn_slz_1`、`w_cn_preview_zc`：本位币及外币逐笔日记账，期初、收付、期末，Excel 导出和打印。
- `w_cn_hz`、`w_cn_hz_1`、`w_cn_wbhz`、`w_cn_wbhz_1`：同年度期间汇总余额表，可选择包含未结月份，列示期初、本期、本年累计、期末；原币按币种分别合计，本位币单独总计，支持穿透、Excel 和打印。
- `w_cn_fz`、`w_cn_fjz`：逐月结账及仅反最近一月，快照复核、独立权限和真实本位币/原币余额保存；十二月生成次年只读期初。跨年后已有业务历史（含软删除及支票）时保护次年期初，反结账保留原单、凭证和勾账。
- 支票管理：领用、签发、兑付或作废，账户票号唯一、金额及日期复核、版本保护、分权与强确认，终态保护及操作日志；不自动生成收付单。
- 账户期初、收付单及支票金额保留原始输入，非法金额阻止保存；关闭抽屉、关闭标签或切换账套可选择保存、放弃或取消。保存失败和保存期间的新编辑均保留，重复提交合并处理。
- `w_cn_km_find`：现金银行与对方末级科目可搜索选择，服务端再次检查有效性。

## 默认处理与范围

- 出纳期初独立于账务期初，二者差额明确展示，不自动改写账务期初。
- 外币收付使用录入或已设置汇率，折合本位币到两位小数；折算不足本位币最小金额时拒绝并提示合并实际收付。本位币与原币历史期初分别录入，不用当前汇率倒推历史余额。
- 文件最多 5 MB、1000 行、60 列；第一行列标题，Excel 读取第一张工作表，旧 `.xls` 需先另存为 `.xlsx`。金额按元，日期为 `YYYY-MM-DD`；空行不导入，有错不做部分保存。
- 批量删除一次最多 2000 张；已生成凭证、已勾账、已结账和预览后改动的单据跳过，清单如实报告。
- 汇总余额表按年度查询，跨年请分别查询；包含未结月份关闭时明确显示实际纳入截止月和排除月份。

## 需要宿主接回

- 重新初始化已接好 `registerCashierResetProtection(app, protect)`（`server/index.ts` 导出），等待宿主把既有完整备份服务注册到此接口。回调第一参数接收 `bookId`、`userId`、`moduleId:'cashier'`、`requestKey`、`reason:'cashier.reset'`，第二参数为可信登录上下文；宿主可据此把已有备份服务绑定到备份身份。须等待保护备份完成并校验，返回 `{id,status:'valid',sha256}`。未接入或备份失败时明确报错且不清空。接入后的浏览器用例核对保护备份中的清空前数据、清空后的出纳状态和账务期初保留；未接入时另有失败保留用例。
- 重新初始化期间若仍有其他调用修改出纳，清空前快照复核会拒绝，要求重新预览；宿主备份不得修改出纳设置或业务表。
