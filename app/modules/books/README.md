未完成 / 需要的共享改动：

- 完整企业科目表仍未完成：原分析只确认a01/a02名称和级次，未确认修订版本；[财政部答复](https://www.mof.gov.cn/bd/mhwzzxly/hjs/202301/t20230104_3861971.htm)区分2006附录和2014年以来指南，不能混拼。现有2019附件是报表格式；[2006官方通知](https://czj.sh.gov.cn/zys_8908/zcfg_8983/zcfb_8985/hj_9035/cwhjjbzdgf/20061201/0017-156907.html)可读，但其RAR附件在本环境返回403，上海税务旧入口404，尚缺完整可核读原表。旧9项JSON、ID及全部 `needsReview:true` 保留，未注册虚构完整版或将2026征求意见稿当生效规则。
- `enterprise-evidence.ts` 提供待完整原文到位后使用的模块内校验：同版本、来源摘要、原表完整行数/顺序、唯一四位一级编号、逐项名称/类别与方向定位、行业范围、双向/无期末余额性质；未知项强制待核，拒绝以类别猜方向及征求意见稿。当前只有合成夹具验证此结构，不证明官方完整表、方向或法律适用性。真实SQLite回归覆盖另注册模板只作用于新账套、旧账套重开不补改、失败清理与整数凭证/基础余额取数；尚无完整企业模板可供验收。
- 小企业为 `small-appendix.pdf` 第1—3页66项原表快照，5403保留“营业税金及附加”；后续更名、专项增补及法定报表尚未覆盖。1702第33—34页第三项贷记与第四项“借方余额”矛盾，按备抵贷方设置并标记待核勘误。
- 其它本位币需共享 `CreateBookInput` / `BookStore.create` 扩展；空白/用户自定义制度受至少一个科目的schema限制，未提供假选项。
- 通用恢复/备份管理归M18，账册与打印设置归M19，科目编码调整归M03，业务设置归M05/M07。未建立这些模块的假链接；首次建账以外的破坏性重新初始化不在本模块实现。
- W0 `TabsHost` 需稳定标题回调并避免无变化时反复生成标签数组；修复后可删除本模块整页菜单导航兼容钩子。跨模块统一跳转仍需共享壳集成。
- 实际删除未实现并已在服务端阻止：最终快照不能覆盖之后的写入，关闭BookStore缓存句柄也无法排空其它连接；在线移动主文件可能遗漏WAL中的晚提交。必须先由共享层提供跨模块/跨进程维护锁，阻止新认证/打开/迁移/读写，排空在途请求并关闭全部连接，消除close期间重新打开的窗口，再设计可恢复文件交换、强确认及会话失效。当前不执行移出、永久删除或崩溃恢复；模块互斥锁与已有备份不能替代这些前提。
- core公共创建接口没有幂等键：本模块阻止同窗口重复点击，但网络响应丢失后的跨请求建账幂等需要共享支持，不能宣称已实现。
