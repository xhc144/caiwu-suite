- 通用恢复/备份管理归M18，账册与打印设置归M19，科目编码调整归M03，业务设置归M05/M07。未建立这些模块的假链接；首次建账以外的破坏性重新初始化不在本模块实现。

- BookStore/SessionStore尚无跨模块请求排空与维护锁；本模块仅序列化自己的复制/删除操作，不能保证与其它模块在途请求或其它进程的全局互斥。删除恢复目录与备份可保留数据，但崩溃后的自动恢复/收据重建及跨进程并发删除仍未实现。
