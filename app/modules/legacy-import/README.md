# 原账迁移

- 系统菜单“原账迁移”：科目、项目/客供/部门/个人/现金流量项目档案、期初余额与凭证可一次导入。
- 支持多表 Excel `.xlsx`、CSV、TSV、分隔文本及直接粘贴；文本支持 UTF-8、GB18030、UTF-16LE/BE，自动识别字节顺序标记。
- 提供四表模板、原版列名别名、自定义列名及数值含义对应；原凭证类型数字编号可按用户核对的字典明确转换，不自行猜测。保留编码首零、原始文件/工作表/行列；异常公式、日期/来源年月冲突、金额精度、层级和档案引用均报明位置。
- 联系人、地址、邮编、电话、开户银行、银行账号、税号、客供角色、分类与现金流量方向均可导入；未指定客供角色时明确提醒并按双向档案处理。
- 先保存迁移资料，再在真实核心事务中预检并回滚；正式导入同事务保存全部账务数据、迁移回执和日志，任一步失败全部回滚，暂存资料保留。
- 相同科目和档案只沿用一致资料，不覆盖冲突；相同期初默认停止，可明确选择替换相同组合，预检展示前后金额。逐年度检查最终期初及累计借贷平衡。
- 自动分配新凭证号并提供原号对照；保留原号要求账套已采用手工编号。同批提交幂等，重复原凭证阻止再次导入；预检后账套变化须重新预检。
- 新凭证统一待审核；原状态、原制单/审核/记账人等来源字段保留。可下载迁移来源及凭证对照 Excel、问题清单 CSV，并逐份取回原始上传文件；解析失败的原文件也原样保留，刷新后可继续操作暂存批次。
- 服务端校验权限、账套隔离、期初锁、月结与年结状态；凭证全部通过共享凭证服务写入。

## 原版导出步骤

1. 新版先建对应会计制度、科目级次和启用期间的账套，维护所需币种、凭证字和结算方式。
2. 原版科目、辅助档案及期初列表使用“数据导出”中的“操作 → 另存”；导出全部末级及辅助明细，避免把汇总数重复导入。
3. 原版“凭证序时簿 → 凭证导出”选择完整日期范围，保留每行的日期、凭证字、原号及辅助编码。也可从“系统管理 → 审计接口”选择年度和导出文件夹。
4. 将取得的表格按模板列名或“列名对应”整理；旧 `.xls` 用表格软件另存为 `.xlsx` 或文本。每份辅助档案填写“辅助类型”，原版未明确含义的数字枚举需先核对后转换。
5. 金额按元填写，最多两位小数；数量最多六位小数。期初方向留空时，本币、外币、数量均借正贷负；填写借/贷时三项均填非负数。年度与凭证期间必须已在目标账套建立且允许写入，跨年资料按年度处理。
6. 每文件最多 8 MB、每批最多 20 文件且合计约 18 MB/5万行；单张凭证最多 999 行，不能跨批拆开。同一批次通过预检后，核对汇总、提醒及期初替换内容，再确认导入。

## 边界

- SQL Anywhere `.bak` 为物理备份，本模块不直接读取；采用原版已导出的 Excel/文本迁移。
- 原版安装资源、运行程序、真实账套及设备/试用版限制不在本模块范围内。
- 不自动恢复原账的审核、过账权限行为；原历史字段可回查，导入后由操作员复核并正常审核、过账。
