# 发票

- `w_fp_lr_1/_2`、`w_fp_cx/_2`：销/进项票头与商品明细录入、日期/单位/票种/未制证查询，审核与来源锁定；当前查询批量删除预览、跳过原因和二次确认；筛选结果 Excel 导出、打印。
- `w_fp_get_xz`：单工作表 XLSX 已知表头别名映射、错误行和重复/冲突预览、整批事务导入；附合成五票样例。同票多商品分组，长号码按文本保存，未知列及公式拒绝。
- `w_fp_sz/_2`：分方向统一末级科目与统一辅助项映射；显式纳税人口径和进项税额单列/计入非抵扣成本配置。
- `w_fp_pz`：已审核发票逐票/同月所选汇总制证预览、来源凭证、幂等重试；未审核凭证可整体撤销，全部来源票同时回退。
- `w_fp_zzs_hz`：年度月/季度账票比对、仅已过账/含未过账口径及票/分录钻取；切回标签、切换口径、查询及显式刷新读取最新数据，显示读取状态并同步已打开明细；启用前标为未启用，跨启用月季度只比对启用后范围；销项按开票月、进项按确认月，差额保留。
- `w_fp_hz`、`w_fp_khhz/_2`：月/季度、客户/供应商汇总，含红字、排除作废，导出和打印。
- `w_fp_fz/fjz`：独立发票月份锁定与反结账，不关闭账务期间，不允许早于账套启用月份。

## 未完成

- 按客户/供应商自动匹配和确认新增下级科目、父科目编码空间检查；按每张票分别指定辅助项、外币及数量科目制证映射。当前统一辅助项应用于所选全部票，需人工核对、按需分次制证。
- 更多数电票平台表格适配、自定义任意列映射、XLS、PDF/OFD/XML 等格式；当前只支持页面样例及明确已知表头的单表 XLSX，其他字段明确拒绝，不能宣称兼容全部数电票。
- 销货/服务分别映射不同收入科目、库存成本结转，以及成本版“转出库单”与仓库联调。
- 逐票抵扣资格/税务资格认定、申报及政策计算；系统不自动认定资格，不提供现行税率默认值，不作税务合规结论。
- 跨标签页关闭/历史导航的统一未保存拦截，需要壳层关闭钩子；当前抽屉关闭及浏览器刷新有未保存确认。更多原版自定义综合查询、打印版式与初始化清空流程。
