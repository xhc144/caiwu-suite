## 制证核算口径与共享接入

- 对照原窗口 `w_fp_pz` 的外币、汇率、数量、单价及辅助项字段。本币金额保持票面金额；外币金额×汇率按四舍五入到分核对，不一致时拒绝生成。此为明确的制证校验默认，不据此认定税务资格或抵扣政策。
- 数量仅在全部商品行单位与科目单位一致时自动合计；其他情况须明确填写。数量最多六位，非零数量的本币单价由金额÷数量计算，可改填但必须与金额相符。零数量可保留金额调整，单价为空。红字保留原借贷侧并使用负金额、负数量。
- 重新生成支持同月原来源与未制证发票合并或拆分；已审核、过账、闭锁月份及不完整汇总组整批拒绝。手工号按删除后重排结果检查占号，确认展示原凭证及受影响编号。失败保留原凭证、发票关联和已保存输入。
- 发票转出库调用已确认的 `previewInvoiceIssue` / 事务内 `saveInvoiceIssue` 窄服务；来源发票、版本、数量、单价、税率及票面整数分由本模块重建，客户端仅选择仓库、科目及产品对应，不接收客户端改写票面金额。原来源关联、库存结果、发票状态、请求记录及日志同事务保存。库存与成本能力不在本模块复制，旧服务能力缺失会明确报错。
- 已有产品的存货或收入科目为空时，页面指引补齐产品档案并刷新目录；服务端拒绝预览，不将空值转为零。已有与新增产品的科目均核对可用末级状态。
- 共享只读 `invoiceIssueReferences({invoiceId})` 返回仓库、产品名称/规格/单位及原来源单的当前版本；不读取库存模块表或借用成本能力。发票税率存为小数，调用库存时按其百分数口径转换单位；票面整数分不重算或改写。此入口还需要共享桥要求的发票制证权限。
- 红字转出库按本轮约定明确拒绝，不取绝对值伪装正常出库；缺少真实商品行、数量或单位的汇总/劳务票也拒绝。新增产品预览不写档案，正式保存须单独权限与确认。转出库后票面和取消发票审核仍锁定；收入凭证可在发票处理生成、原子重建或撤销，均不重复出库、不改变库存和成本凭证。调整出库单须先撤销未审核收入凭证，再解除原单审核、核算等业务锁并确认替换。直接撤销出库关联尚无共享接口。
