# 工资

对照原版 `docs/original-analysis/products/minfeiqi/main/` 的工资、人事、公式和凭证设置窗口，功能如下。

| 原窗口 / 菜单 | 可用功能 |
| --- | --- |
| `w_gz_rsgl/_ins/_xg` 人事档案 | 新增人员、修改编号及姓名、任职起止、部门、停用和居民计税资格；修改编号保留历史关联。 |
| `w_gz_bmwh` 部门维护 | 新增、修改编码名称、确认停用及启用；稳定部门标识保留关联，删除前展示引用并确认，人员、工资快照及凭证映射引用阻止删除。 |
| `w_gz_edit_set` 人事统一置数 | 对所选或当前筛选人员的九类基本项预览后统一修改；支持空白项补值，编号不可批量覆盖；人员或部门变化使预览失效，任一保存失败整批回滚。 |
| `w_xt_gzsz` 工资结构 | 多类别金额及计算栏目、显示/打印/传递、结构版本及历史快照。 |
| `w_xt_gssz/gs_edit` 公式 | 白名单算术、比较、逻辑分组、条件和数学/日期函数；依赖顺序、参数个数、错误位置及循环检查，失败不覆盖上次计算。 |
| `w_gz_gzgl` 工资编辑 | 主表逐格录入金额，Tab 切格、Ctrl+S 保存、确认放弃；筛选及分页不移除范围外人员，公式及计算结果只读，修改后明确待重算。支持抽屉录入及另存；冲突或保存失败保留输入，关闭和离开接入统一未保存保护。 |
| `w_gz_edit_set` 工资统一置数 | 所选人员金额置数、空值设零、TSV 粘贴、修改前后预览、取消及变更检查。 |
| `w_pz_sz/build_gz` 制作凭证 | 标准发放/部门分配，以及任意启用金额项、计算项和应发/实发/扣款/个税的借贷科目映射；同栏目可按部门覆盖费用科目。预览绑定设置及工资版本，事务生成真实来源凭证，重复生成和审核/过账来源受保护。 |
| `w_gz_prt_gzb/prt_hzlm` 工资输出 | 所选人员工资条、工资表、部门/栏目汇总，Excel 导出和打印；空选阻止输出。 |
| `w_gzgl_lshz/w_gz_prt_pm` 累计及票面 | 期间范围人员累计、部门汇总、来源批次；所选金额栏目人民币票面分解、余款、Excel 和打印。 |
| `w_gz_jz/qxfz` 工资结账 | 冻结本月、传递栏目建立下月；最近月反结账、启用边界及已修改下月数据保护，不改变账务期间状态。 |
| `w_gz_zhcx` 综合查询 | 字段及操作符白名单、金额/日期筛选、URL 条件、金额排序和导出。 |
| `w_xt_kgzb_1_gz` 个税参数 | 带来源及版本的居民工资累计预扣参数确认、跨类别累计、计算解释和重算前后对照。 |

自定义映射中，有规则的凭证种类完整采用这些规则，没有规则的种类沿用标准设置。每个栏目独立计入，指定部门规则覆盖该栏目的通用规则，不能重复定义同种类、栏目及部门。金额使用整数分保存，界面按元录入；负额、外币/数量科目、必需部门以外的辅助核算及超过 999 条分录会明确阻止生成。

公式支持 `abs/min/max/sum/round/trunc/truncate/int/floor/ceil/ceiling/sign/mod/if/iif`，以及 `and/or/not`（或 `&&/||/!`）和比较。条件非零时执行，分支和逻辑运算短路；金额变量及结果以分计算，`round(base,-2)` 表示舍入到整元。

日期函数为**本版约定**：`today()` 返回工资期末，`daybefore(YYYYMMDD,天数)`、`monthbefore(YYYYMMDD,月数)` 返回前推日期，月末夹取目标月最后一天；偏移须为非负整数。日期值仅用于日期条件/日期回退，不作金额，也不能直接相减求跨月天数。原版静态窗口和规则只记录函数名与括号、逗号、缺参校验，未载明参数含义，本版不据此声称与原版日期语义等价。
