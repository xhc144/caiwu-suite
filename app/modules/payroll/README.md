# 工资

适用于民非企会计和成本会计；轻松会计的全部工资接口均拒绝访问。对照原版 `docs/original-analysis/products/minfeiqi/main/` 的工资、人事、公式、打印及系统窗口。

| 原窗口 / 菜单 | 可用功能 |
| --- | --- |
| `w_gz_rsgl/_ins/_xg` 人事档案 | 新增、改编号、停用、断续任职及返聘；自定义文字/日期资料、所选人员 Excel 和打印；定位和记录移动，删除前检查工资及历史引用。 |
| `w_gz_bmwh` 部门维护 | 新增、修改、停用和启用；稳定标识保留关联，人员、工资快照和凭证辅助映射引用阻止删除。 |
| `w_gz_edit_set` 人事置数 | 对所选或筛选人员的基本项及自定义资料预览后统一修改，支持空白补值；版本变化拒绝覆盖，任一失败整批回滚。 |
| `w_xt_gzsz` 工资结构 | 多类别金额、数量、计算和基本信息栏目；单位、说明、宽度、显示、打印及传递，结构版本和历史快照保留。 |
| `w_xt_gssz/gs_edit` 公式 | 白名单算术、比较、逻辑分组、条件及数学/日期函数；依赖、参数、错误位置和循环校验；可明确选择唯一一条自定义计税公式。 |
| `w_gz_gzgl` 工资编辑 | 主表逐格及抽屉录入，金额按元、数量按原单位；Tab、Ctrl+S、定位及记录移动；筛选和分页保留范围外人员，冲突或失败保留草稿。 |
| `w_gz_edit_set` 工资置数 | 金额/数量统一置数、空值设零及 TSV 粘贴，前后预览、确认、取消、过期和版本检查。 |
| 工资 Excel 转入 | 上传 `.xlsx`、选择工作表和栏目映射，按人员编号预览新增或覆盖；空格保留原值，非法内容整批拒绝，失败保留文件和输入。 |
| `w_xt_kgzb_1_gz` 个税参数 | 居民普通工资累计预扣参数与来源确认；历史按月税制分别确认，计税明细可核对，跨类别累计不重复享受扣除。 |
| 前期更正 | 已计算批次的金额、数量、扣除及期初数预览后更正；按人员依赖级联重算，保留更正原因及前后快照；已结账或有来源凭证的批次受保护。 |
| `w_pz_sz/build_gz` 工资凭证 | 标准发放/部门分配及任意金额或计算项借贷映射；支持项目、客供、个人、部门和现金流量辅助；红字调整、必要时按科目及完整辅助汇总。 |
| 工资凭证撤销 | 展示删除及后续编号变化，确认后事务撤销；审核、过账、过期计划及来源版本检查仍生效。 |
| `w_xt_dysz/w_gz_prt_gzb/prt_hzlm` 打印输出 | 工资表、工资条和汇总各自保存栏目、顺序、列宽、整数/小数位、页边距及页脚；预览缩放和重选，分页和超页检查，Excel 与真实打印。 |
| `w_gzgl_lshz` 累计汇总 | 人员累计和部门汇总可明确合并多个类别；检查同名栏目类型及单位，列出来源类别、期间和批次。 |
| `w_gz_prt_pm` 票面计算 | 选择金额栏目和人民币面额，逐人逐期整数分解及余款；URL、Excel 和打印保留栏目，非法或负金额阻止计算。 |
| `w_gz_jz/qxfz` 工资结账 | 冻结本月及传递下月；已有下月数据可预览补缺并保留原值，已修改下月可明确保留数据反结账；最近月、启用边界及账务期间检查。 |
| `w_gz_zhcx` 综合查询 | 白名单金额/文字/日期条件、条件组内和组间全部/任一组合、多列排序；URL、刷新和 Excel 采用相同条件。 |
| `w_xt_kgzb_gz` 工资初始化 | 管理员完整密码、影响预览及明确确认，清空前实际备份并回装核验；可保留档案或原启用期间以后数据，修改工资启用期间；保留数据时新启用前批次须已计算，来源凭证和已结期间阻止破坏。 |
| `w_xt_kmwh_copy` 工资转入 | 转出工资文件，在另一账套按部门/科目/辅助编码映射后预览覆盖；目标先备份，失败整批回滚；历史税额保留并标记来源，保护副本可预览恢复。 |

金额使用安全整数分；数量使用十进制字符串传输，以六位小数整数保存。工资、扣除及置数的非法原文同步阻止按钮和快捷键提交，不沿用旧金额；分页、保存失败、并发更新及离开保护保留编辑内容。外部更新须明确重新载入。

自定义映射中，有规则的凭证种类采用完整规则，没有规则的种类沿用标准设置；指定部门规则覆盖该栏目的通用规则。超过 999 条时仅合并科目、辅助、借贷方向及红字符号均相同的分录，汇总后仍超限须拆分。外币/数量核算科目仍阻止直接制证。

内置历史月减除费用：2008年3月至2011年8月为 2000 元九档，2011年9月至2018年9月为 3500 元七档，2018年10月至12月为 5000 元新七档；2019年起为居民工资累计预扣。来源见计税参数页面。自定义计税须有参数配置权限，结果为非负整数分，目标为备查计算项，个税只扣一次；它不等同于已实现其它所得的专用税制。

公式支持 `abs/min/max/sum/round/trunc/truncate/int/floor/ceil/ceiling/sign/mod/if/iif`、`and/or/not`、`&&/||/!` 和比较，条件及逻辑短路；金额变量和结果以分计算，`round(base,-2)` 舍入到整元，数量变量以原单位参与计算。

日期函数采用本版约定：`today()` 返回工资期末；`daybefore(YYYYMMDD,天数)`、`monthbefore(YYYYMMDD,月数)` 前推日期，月末夹取目标月最后一天，偏移须为非负整数。日期只用于日期条件或回退。原版静态资料未载明参数含义，不据此声称原版日期语义完全等价。

未完成：

- 同类别同月多批次、工资批次冲正及复杂补扣冲正；历史人事任职和计税身份更正不自动改写已计算快照。
- 自定义人事资料直接参与工资公式；当前工资结构仅引用固定公开基本项。
- 原版旧 `.xls` 文件直接读取（可先另存为 `.xlsx`）、重复内容隐藏和其它专用汇总布局。
- 共享壳的窗口排列、打印机设置、Ctrl+F4 等动作由壳负责；本模块不声称完成原版全部窗口快捷键的逐项等价。
