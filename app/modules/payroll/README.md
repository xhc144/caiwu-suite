# 工资（payroll）

功能：

- `w_gz_rsgl/_ins/_xg`：唯一人员编号、姓名、core 部门、任职起止、停用；改编号保留历史。
- `w_xt_gzsz/gssz/gs_edit`：多工资类别、金额/计算栏目、显示/打印/传递标志；安全基础算术与条件公式、定位错误、结构版本和批次快照。
- `w_gz_gzgl`：期间/类别工资录入、逐人累计扣除和期初税额、居民工资累计预扣解释、跨类别合并及重复计算；显式确认简便方式资格；非居民、劳务、年终奖等拒绝自动计税。
- `w_pz_sz/build_gz`：按部门的工资发放/分配预览、过期预览阻止、待审核来源凭证、确认撤销、来源锁定。
- `w_gz_prt_gzb`：所选人员工资条 Excel 与打印，数据取自计算快照，空选择阻止输出。

- Excel 粘贴/导入、统一置数/空值置零预览、逐格主表编辑、重算前后对照；同类别同月多批次。
- 专项附加逐项目资格/分摊自动推算、期初免税收入分项、任职断续记录与前期更正；非居民、劳务、年终奖、特殊行业税制。
- 工资表、部门/所选栏目汇总、累计汇总、票面分解及相应输出。
- 任意工资项贷方映射、部门不同费用科目、部门以外辅助维度、负额凭证、超过999条的分录汇总。
- `w_gz_jz/qxfz`：工资独立结账、下月传递、最近月反结账及启用期规则。
- `w_gz_zhcx`：字段/操作符白名单综合查询与排序；完整未保存离开拦截（当前抽屉关闭、链接离开及刷新提示）。
