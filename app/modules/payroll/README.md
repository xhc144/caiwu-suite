# 工资（payroll）

功能：

- `w_gz_rsgl/_ins/_xg/bmwh`：唯一编号、姓名、core 部门、任职起止、停用；改编号保留历史。
- `w_xt_gzsz/gssz/gs_edit`：多类别金额/计算栏目、显示/打印/传递标志、安全基础算术和条件公式、定位错误、结构版本快照。
- `w_gz_gzgl/xt_kgzb_1_gz`：工资录入、居民工资累计预扣解释、累计扣除与期初税额、显式资格选择、跨类别累计、重复重算及前后快照对照。参数保留官方来源、版本和适用范围。
- `w_gz_edit_set`：所选范围置数/空值置零、Excel 制表符粘贴、修改前后预览、确认/取消与过期保护。
- `w_pz_sz/build_gz`：部门分配/发放预览、设置版本、事务生成待审核来源凭证、确认撤销与审核/过账锁。
- `w_gz_prt_gzb/prt_hzlm/gzgl_lshz/prt_pm`：所选工资条、工资表、部门/栏目及人员累计汇总、整数票面分解；Excel 与打印，空选择和负实发票面阻止。
- `w_gz_jz/qxfz`：本模块期间冻结、传递栏目建下月、重复结账去重、最近月反结账与未修改传递数据回退；不改变账务期间。
- `w_gz_zhcx`：字段/操作符/金额/日期白名单条件、URL 保留条件、金额排序和查询导出；金额/科目/部门组件及列宽记忆。
