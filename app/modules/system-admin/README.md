# 系统管理

- `w_login` / `w_login_oem`：真实 core 登录、账套检查、键盘提交；不设旧版试用、注册与加密狗限制。
- `w_login_1`：确认未保存风险，退出当前会话、清空缓存并返回同账套登录页。
- `w_xt_users` / `w_xt_uses_zj` / `w_users`：新增、改名、启停；保护自己和最后启用管理员，保留历史引用。
- `w_xt_users_qx` / `w_grant`：动态模块权限树；管理员授权，未加载模块历史权限保留，目标旧会话失效。
- `w_pass`：原密码验证、8–64 字符新密码及确认；管理员确认目标后重置。成功后当前账套旧会话全部失效。
- `w_xt_dlxx`：账套日志筛选、分页、白名单详情和 JSON 导出；默认本月、列宽记忆与确认恢复。
- `w_zh_zhjc`：只读科目、期初、凭证头行、零额行、借贷、余额取数、断号、未过账及期间检查与处理链接。
- `w_bf_98001`：年度/范围、数量及金额预览、过期预览保护、白名单通用审计 JSON 文件。
- `w_xt_kgzb` / `_0` / `_1` / `_2` / `_3`：真实账套、模板、期间和数据数量预检，明确禁用破坏性执行。

未完成：物理删除用户；开账日期调整、自动修复与初始化执行（缺账套独占锁、完整在线备份及原子重置服务）；审计标准官方全文逐字段及输出格式核对；任意模块日志自由详情解析；壳顶栏切换用户入口。
