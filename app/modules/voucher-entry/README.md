# 凭证录入（M05）

功能清单：

- `w_pz_pzedit` / `w_pz_pzedit_b`：`/new`、`/edit?id=...`；类型、真实日期/期间、附单数、自动编号提示及服务端编号，制单/审核/记账信息；草稿、正式保存、保存并新增。
- 全空分录行在保存时忽略，半填行按原行号提示。零本币但有原币或数量的分录须明确借贷方向，保留折算及数量校验。
- 借方、贷方和原币金额的非法输入保留原文，失焦、关闭再打开分录信息或插删前行均不丢失；修正前阻止正式保存、草稿和自动保存，关闭标签、切账仍提示未保存，明确放弃才恢复已存内容。凭证模版使用相同保护。
- 分录网格：列宽可拖动或用键盘调整并记住；摘要库、科目编码/名称/拼音搜索、项目/客供/部门/个人/现金流量、期间余额（含已保存未过账）、外币汇率/原币、数量/单价、结算类别/票号/业务日期。数量按六位小数储存，乘积及外币折算四舍五入到分；红字保留符号。外币本位币与原币×汇率不一致时，正式保存、模版、审核入口及粘贴预览均按行阻止并列出应填金额/差额；草稿仅保留编辑状态且显示不一致提示，不提供差额豁免。
- `w_pz_flxx1` / `w_pz_km_find`：分录抽屉显示摘要、完整科目层级和辅助项编码名称；停用、非末级、缺失及未启用维度有行级校验。
- `m_work_pz_pzedit`：Enter 移格和末行新增；Ctrl+I 插行、原版 Ctrl+D 与新增 Ctrl+K 删行、原版 F5 与新增 Ctrl+S 保存、`=` / Ctrl+H 找平当前金额格、F7 平衡复制、F8 当前行借贷互换、F4 科目搜索、F6 分录信息、F3 科目维护、Ctrl+T 凭证复制导航、Ctrl+P 打印导航；快捷键限可见标签页并避开输入法组合；科目档案加载期间不开放选择，抽屉关闭后不会延迟抢走已进入下一格的焦点。
- 自动保存串行、首次创建幂等、core revision 与缓冲版本冲突检查。core 草稿不编号、不入账表；无科目行只在本模块编辑缓冲保留。正式凭证自动保存只写编辑缓冲，手动保存才更新正式记录。缓冲记录对应的 core revision，旧缓冲须显式恢复。关闭标签再快速重开时强制读取最新缓冲和凭证 revision，保存后同步/失效对应缓存，不复用最初的空缓冲。
- 离开确认期间暂停防抖自动保存；放弃修改恢复上次持久化快照后离开，不删除已存草稿，不把待放弃内容延迟保存。
- `w_pz_pzedit_mb` / `w_pz_pzmb_add` / `w_pz_pzmb_main` / `w_pz_pzmb_xz`：模板列表、搜索、增加、改码改名、编辑分录、删除确认、转模版、调用确认、失效引用展示与重校验。模板头和分录事务保存，不携带原凭证编号、来源、人员或凭证 revision。
- Excel 文本粘贴：列映射、只按编码解析、整数分预览及逐行错误，确认后替换；取消保留原内容，正式保存仍走 core 校验。
- 首张/上张/下张/末张按期间、类型、编号和 ID 稳定移动；已审核/过账、作废、来源凭证只读，按来源 manifest 跳转。复制/反冲（`w_pzedit_copy` / `w_pzedit_fc`）、审核、反过账、科目维护、出纳、打印仅导航到所属模块。
- 保存、模板和审核导航入口检查真实 `cashflowRequired`，本地校验 `attrs.cashflowDirection: inflow | outflow | internal`，核验方向和内部配平。历史/演示项目缺少方向时明确显示“方向未配置，无法核验”，确认保留的内容仍待核验。
- 模板支持 Enter 移格、末行新增、F5/Ctrl+S 保存、Ctrl+I 插行、Ctrl+D/Ctrl+K 删行、F4 科目搜索、F6 分录信息及 Ctrl+F4 返回；输入法组合和隐藏标签不抢键。重输分录须确认。
- 模板保存期间可继续输入，响应只更新已保存版本的标识，保留新名称、分录及未保存提示；再次保存更新同一模板。凭证和模板接入统一未保存守卫，保存期间的新编辑不会因离开而丢失。
- 分录余额按当前辅助组合过滤，同时显示外币和数量余额。修改日期会清除旧期间汇率；带入新汇率保留借贷方向、红字及零本币分录的明确方向，溢出不改原行。
- F9 计算器支持四则、括号、正负和清除，明确回填当前借贷格；输入直接接收键盘，父弹窗入场后保持算式焦点，取消返回原金额格且不改金额。无效算式、除零和超额结果不能回填。
