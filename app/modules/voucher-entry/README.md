# 凭证录入

功能清单：

- `w_pz_pzedit / w_pz_pzedit_b`：新增、查看修改、草稿、正式保存、保存并新增；正式保存和模板忽略全空行，半填行与非法数字保留原行号，失败不丢输入。
- `w_pz_km_find / w_pz_flxx1`：科目搜索、辅助核算、票号与业务日期、按辅助组合及币种读取余额、外币和数量折算；停用、非末级、必填、借贷平衡和版本冲突检查。
- `m_work_pz_pzedit`：Enter 移格、F5 保存、F4 搜索、F6 分录信息、F7 平衡复制、F8 借贷互换、插删行与找平；金额进入时全选，保留手动选区、负数、粘贴和输入法。
- `w_pz_pzedit_mb / w_pz_pzmb_add / w_pz_pzmb_main / w_pz_pzmb_xz`：模板增改、读入、删除与重校验，全键盘编辑，保存响应期间保留新输入，离开提供保存、放弃、取消。
- `w_calc`：F9 白名单四则计算、括号、正负与舍入，明确回填金额；自然入场、连续 Enter、取消后回到原格。
- 自动暂存串行、排队任务出队复核、正式记录与暂存内容分离、旧版本显式恢复；记录移动和本域离开确认等待当前保存，放弃后旧任务失效，隐藏页不抢快捷键。
- Excel 文本粘贴预览；已审核、已过账、作废和来源凭证只读；复制、反冲、审核、打印和期末处理导航。

未完成项：

- 统一的关闭所有、浏览器历史、切换用户/账套和桌面退出保存协议需接入共享接口；当前保留本域确认及浏览器原生提醒。合法零本币但非零外币/数量行已保留并通过本域检查，正式持久化仍受共享凭证服务的零金额限制。
- 编号方式、用户间修改策略和现金流量强类型字段需接入共享服务；方向未配置仍要求明确确认。
- 汇兑损益完整流程、合同与财务/预算双体系、海关字段、手工结转标志、现金流量自动匹配、出纳引入及断开挂接、辅助档案快捷维护回跳和特殊打印参数入口尚未补齐。
- 模板继承的隐藏审核、反冲、打印等事件及独立首末记录导航未全部实现；原厂时钟版授权规则不作为新软件的授权方式。
