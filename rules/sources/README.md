# 来源与自研实现分开

本目录 `official/` 为主管机关公开规范、正式附件及官方说明/状态网页的原始字节副本；未改正文。对应URL、文号、成文/生效日期、获取日期、文件SHA-256、字节数及资料缺口在 `../sources.json`，离线验证逐个核对。

`rules/.gitattributes`将原始证据设为binary，保留官方原有换行和空白，不参与自动换行转换或正文合并；Windows检出也不能改变其hash。自研代码、JSON和说明照常使用文本diff。

`../packages` 中的字段设计、通常方向元数据、工程样例编码、代表行表达式及适用选择器是本项目自研整理，不是财政部发布的软件或机器规则。`../runtime.py` 及测试为自研代码。没有商业安装包、运行库、图标、截图或反编译代码。
