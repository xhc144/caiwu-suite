# 财务套件开发预览：安装与使用

本说明用于 Windows x64 开发预览的合成账套试用。最终候选仍待交付负责人完成独立验收并确认，不能据此用于正式账务。确切版本、安装包名称和校验值以最终交付清单为准。

## 安装和启动

收到经交付负责人确认的安装包后，先核对随包清单，再运行安装程序。当前候选为未签名程序，不是官方签名发行版；遇到 Windows 安全提示时保留提示并核实来源，不关闭安全防护。

安装程序面向当前 Windows 用户，采用自包含 .NET 运行环境。当前代码默认把程序放在 `%LOCALAPPDATA%\Programs\CaiwuSuite`，数据放在 `%LOCALAPPDATA%\CaiwuSuite\Data`。自定义目录应在安装时确定，程序与数据目录必须分离；不要把账套放进程序版本目录。

使用开始菜单中的“财务套件”受管启动入口。需要由支持人员检查启动时，使用随安装交付的工具执行：

```text
Caiwu.Delivery.exe launch-managed "<installRoot>"
```

`<installRoot>` 是实际安装根目录。启动器负责校验当前版本、安装回执及数据根，再启动桌面程序。不要直接双击内部 `Caiwu.Desktop.exe`，也不要手工设置环境变量、改清单或删除锁文件来绕过校验。启动失败时先保留完整错误信息。

## 首次设置与角色

1. 首次启动填写管理员登录名、显示名和自定密码，密码为 12–128 个字符。没有默认密码。
2. 设置成功后还要在独立登录窗口中显式登录。取消设置或取消登录都不会进入可写账务会话。
3. 在“系统管理 → 操作员管理…”中为试用人员建立独立账户并分配角色。管理员不会自动获得全部账务权限。

| 角色 | 主要用途 |
| --- | --- |
| 管理员 | 管理操作员、创建或恢复账套 |
| 会计 | 科目、期初余额、账套备份 |
| 制单 | 新增草稿，修改或删除本人草稿 |
| 审核 | 审核、取消审核 |
| 记账 | 记账已审核凭证 |
| 结账 | 关闭会计期间 |
| 只读 | 查询与报表 |

角色可以多选；同一可信身份仍不能审核本人制单的凭证。登录名创建后不可变，显示名用于展示，系统生成的可信 Actor 身份用于业务归属；改显示名或顶栏文字不能换人。用“系统管理 → 注销并切换操作员…”重新登录。本人改密、角色变更或停用会使旧会话失效，旧窗口不能接着以新身份保存。

旧账务中的自由文本姓名不自动对应新账户；无法核实归属时可能拒绝编辑或审核。当前不提供原软件账套自动导入、旧身份自动映射、跨年度自动迁移或原地数据库版本迁移。

## 从新账套到记账

1. **新建账套。** 在“文件 → 新建账套…”填写名称、会计制度、年度和启用月份，在受管数据根内选择新的 `.caiwu` 文件。制度与模板版本建立后固定；当前为单年度人民币基础账务，企业模板也须核对科目，不能视为完整生产制度包。当前不开放民非账套新建。
2. **科目与期初。** 在“会计档案 → 会计科目”核对科目、方向、层级与启用状态；在“期初余额”录入并点击“保存期初余额”，核对借贷合计。切换页面或退出前处理未保存输入。
3. **制单。** 由有制单角色的账户新增凭证，填写日期、摘要、启用末级科目及借贷金额，确认平衡后保存。保存得到草稿，不等于审核或记账；“附件数”只是数量字段，不代表已归档凭证影像。
4. **审核。** 注销并由另一位审核人员登录，在“凭证序时簿”查询、选中草稿，核对后审核。已审核凭证只读；需要修改时先按权限取消审核。
5. **记账。** 由有记账角色的账户选择已审核凭证并确认记账。当前没有反记账入口，已记账凭证不能直接修改或删除。
6. **查询账簿。** 在“科目余额表”和“明细分类账”选择期间与科目并查询；检查记账后的发生额与余额。通过“报表 → 账簿报表与导出…”生成余额、明细或凭证清单，双击余额科目进入明细，双击发生分录查看凭证。

需要月度结账时，由有结账角色的账户检查本月账务、先备份，再使用“实务操作 → 月度结账…”。本版没有自动年结或滚年流程。CSV、HTML 是输出文件，不替代完整账套备份；打印效果、中文输入法和不同 DPI 仍需在使用设备上核对。

## 常用工具的实际范围

| 入口 | 操作与限制 |
| --- | --- |
| 实务操作 → 复制凭证为新草稿… | 先在凭证列表选中来源，确认复制计划，核对新草稿后点击“保存新草稿”。不会继承审核或记账状态；取消不创建凭证。若提示“已保存、刷新失败”，先重新查询，勿重复保存。 |
| 凭证编辑器 → 选择摘要 | 选择当前分录后，从已初始化的本账套摘要库选择一条摘要；确认仅回填当前行，仍须点击保存并关闭。取消保留原输入；只读凭证不能回填，原操作员会话、账套或摘要库版本变化时拒绝回填并保留输入。 |
| 会计档案 → 常用摘要管理… | 首次需明确确认创建当前账套的摘要库。新增分类或摘要后点击“保存更改”；搜索无结果不沿用旧选择。已登记摘要库损坏或缺失时报错，不自动重建。此管理入口不会把摘要自动填入凭证或保存凭证。 |
| 会计档案 → 复制账套… | 输入不同名称与新的受管目标，生成预览、核对范围、勾选确认后复制。可选结构化全量或仅科目及期初；全量限账套结构化数据，不含实际附件文件、摘要库、成本表、报表模板或全局账户。结果是新身份账套，成功后仍停留在源账套；这不是完整备份。 |
| 实务操作 → 成本工作表（审核建议）… | 录入阶段、费用池、成本对象和分配基础，点击“计算 / 复算”并核对尾差及来源。仅覆盖有限的整批完工及阶段承接，结果是人工审核建议，不自动生成总账凭证或记账。修改输入后须重新计算；使用“保存并登记受管审核工作表”才把该 JSON 纳入完整备份，普通导出不等于登记。 |
| 报表 → 民非报表分类与预览（当前月）… | 仅已有实验民非账套可用，其主账务仍只读。先在凭证查询日期选定完整同一月份，再明确填写科目语义、分录分类、余额事实与复核依据。缺项保持缺失，不猜分类、不把未知额补成零；两表计算通过仍是预览。另存分类 JSON 后关闭窗口，检查主窗登记结果，再做完整备份。 |
| 报表 → 自定义当前账表… | 从当前凭证列表、余额表或明细账打开，核对期间与筛选。可调整列、标题、宽度、格式、有限逐行公式及小计，预览后保存模板或导出。不是任意拖拽画布，不支持跨表取数、宏或完整法定报表；截断预览不能导出或打印。模板保存在指定受管目录，关闭窗口后检查登记结果；HTML/CSV 输出位于受管 `Exports` 目录，不自动成为备份附件。 |

工具窗口绑定打开时的账套、期间和登录身份。来源变化或提示会话失效时，先保留输入，关闭后重新查询并打开；不要连续重试来覆盖冲突。菜单不可用时先看提示，核对角色、账套制度、当前页面和所选凭证。

## 快捷键要看所在窗口

| 上下文 | 快捷键 | 行为 |
| --- | --- | --- |
| 主窗口 | Ctrl+Shift+N / Ctrl+O | 新建 / 打开账套 |
| 主窗口 | Ctrl+N / Ctrl+L | 新增凭证 / 转到凭证序时簿 |
| 凭证编辑器的分录表格 | F4 | 为当前行选择科目 |
| 主窗口的凭证序时簿 | F4 | 审核当前所选凭证，仍需权限及非本人制单 |
| 凭证编辑器的分录表格 | F7 | 按其他行差额平衡当前行；本行摘要为空时可沿用上一行摘要。不是整张凭证复制。 |
| 凭证编辑器 / 主窗期初余额页 | Ctrl+S | 分别保存该凭证 / 保存期初余额 |
| 主窗口 | F10 | 确认建立当前账套的受管完整备份，需备份权限 |

这些键不是所有弹窗的通用命令。遇到焦点或输入法问题可使用对应按钮，并保留问题发生时的窗口和输入信息。

## 备份、恢复与数据保留

用“文件 → 备份当前账套…”或主窗 F10 创建**受管完整备份**。成功后状态栏会给出独立可信哈希收据的位置。备份目录位于数据根的 `.delivery-backups/managed`，收据位于 `Global/BackupReceipts`；存档时同时保留完整备份目录及独立可信收据。只复制 `.caiwu`、某个 JSON 或导出报表会遗漏内容。

完整备份包含账套及成功登记的摘要、成本工作表、民非分类和报表模板。保存了文件但登记失败，不能当作已经保护；保留文件与错误，待核对登记。发现未登记模块文件时，完整备份会拒绝完成。

“文件 → 从备份恢复副本…”当前只接受本机受管收据目录中的可信收据，并恢复到新的物理账套实例后打开，保留源账套和原备份。恢复副本与“复制为新账套”不同：它保留原账套业务身份。不要把陌生备份重新算出的哈希当作可信收据；**跨机迁移、新数据根恢复和便携导入不受支持。** 收据绑定原数据根内备份的绝对路径；应保持数据根及原备份目录的路径、名称和内容不变。把备份和收据复制到新目录，不会得到可用的恢复入口。

**全局操作员必须单独处理。** 单本账套备份不含全局账户、密码哈希和停用状态，账套恢复也不覆盖它们。当前主界面没有身份备份/恢复按钮；需管理员由支持人员使用受控接口单独备份，并保管其可信收据。身份备份含密码哈希，应限制访问。不要手工覆盖活动 `Global/Operators` 目录；仅备份账套不足以完成整机恢复。

更新前先完成完整账套备份及单独身份备份，关闭所有使用该数据根的窗口，再使用经确认的升级包。程序在用、回执不符、备份不完整或安全校验失败会阻断升级，不应删锁、清空数据根或强行改标记。已有隔离 Windows 安装验证覆盖忙态阻断、正常升级、升级后登录，以及账套、已登记摘要、备份和全局身份文件的保留；最终交付包仍须重新验收。其它模块完整编辑链、任意旧预览版本和异常中断不由这些结果保证。

卸载的设计是删除已核对的程序文件，保留账套、备份、身份和未知文件。卸载前仍应备份，不要手工删除数据目录。断电、中断卸载、旧预览包和未知数据库版本需要单独核验，不能用重装代替数据恢复。

当前没有可用的私有自动更新 feed 或已配置的下载凭据，自动更新默认关闭。现有组件只提供受限检查、下载暂存及签名校验门槛，不会自动安装；启用需要可信 HTTPS 来源、发布者配置和独立验证，不能输入任意网址当作更新源。

## 故障时保留什么

记录所在窗口、操作步骤、错误全文、账套位置和当前版本信息；关闭程序后保留数据目录副本、完整备份、收据及失败时已生成的新文件。版本冲突先保存仍可见的输入，再重新载入核对；文件已创建但登记失败时不要直接删除或重复创建。不要上传真实账务、密码或身份备份；向支持人员提供脱敏信息。不要关闭 Windows 安全防护、删除锁文件、篡改收据或用空库替换损坏账套。
